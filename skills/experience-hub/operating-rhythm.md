# Experience Hub Operating Rhythm

## 即时

- 每次出现新错误，先记录事件。
- 每次 agent 出错，立即补 validation。

## 每次学习块结束

- 检查今天的错误主要集中在知识、过程，还是复盘质量。
- 只提炼 1-3 条最能改变下次行动的经验。

## 每周

- 跑一次 pattern mining。
- 重排下周 Topic 优先级。

## 每次 Mock

- mock 前生成 brief。
- mock 后生成 retro。

## 每月

- 跑一次 anti-rot review。
- 清理过时 strategy / validation。
