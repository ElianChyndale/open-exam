# CFA Intent Router

Classify the incoming request into one of six workflow intents:

- `record-mistake`
- `review-session`
- `mine-patterns`
- `pre-mock-brief`
- `post-mock-retro`
- `audit-agent`

Prefer the smallest workflow that preserves the evidence trail.
