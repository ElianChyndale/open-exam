# CFA Bias Detector

Map learning friction to a bias label, then write:

- signal
- root cause
- fix rule
- next drill

## Use this when

- the user knows they are stuck but the issue is not one isolated wrong answer
- timing, careless reading, panic, or formula setup keeps recurring
- the content explanation alone would not solve the performance problem

## Output standard

- label the bias clearly
- separate symptom from root cause
- give one behavioral correction the user can actually run next session
