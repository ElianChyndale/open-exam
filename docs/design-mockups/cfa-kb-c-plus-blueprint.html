C+ Blueprint: Curriculum Playbook Complete

这套设计把每个知识点放到它该在的位置：先跟随原版教材讲清楚，再把它翻译成考试动作，最后把基础题、mock、错题反思和复盘规则回填到对应知识点。中文负责理解，English terms 负责精确识题。

Design Principle

核心原则

教材是骨架

每个 Module 的主顺序来自原版教材 chapter sections，不再把教材锚点孤立放表格。教材小节直接成为正文知识块。

考试是翻译层

每个知识块都要转成 question trigger、formula choice、decision rule、trap check，而不是停在定义解释。

题库是证据层

Practice 和 mock 进入对应知识块的 Evidence，不再漂浮成孤立题目列表；错题规则继续回到 .system/memory。

MOC C+

MOC 是科目地图

MOC 不承担大段讲解。它负责导航、优先级、跨模块关系、公式地图、题库入口和复习路线。你打开 MOC 应该马上知道“先去哪一页、为什么、做什么”。

  • 删除机械的“教材锚点表”感，改成 Module Atlas。
  • 每个模块显示：教材章节、核心任务、最高频考点、题型、链接到 Practice/Mock。
  • 新增 Subject Routes：首轮学习、刷题补洞、mock 前冲刺、错题回炉。
00-Subject-MOC.md 新页面结构
1. Subject Brief 科目定位一句话主线、考试权重、最重要的 learning output。
2. Module Atlas 模块地图每个 Module 的 textbook chapter、核心任务、难度、题型、Practice/Mock 入口。
3. Curriculum Spine 教材主线把官方教材小节按概念层、计算层、解释层、跨科目接口分组。
4. Exam Route 做题路线definition route / calculation route / interpretation route / comparison route。
5. Formula & Framework Map公式不是堆表，而是按触发条件与禁止条件分类。
6. Practice & Mock Evidence Map基础题、mock、unclassified mock 后续都能落到模块和知识块。
7. Review Routes 复习路线首轮、二轮、mock 前、错题回炉各自看哪些模块和段落。
Module C+

Module 是完整学习章节

Module 会变长，但更有秩序。它不再是“前面旧笔记 + 后面补表格”，而是一章从教材到考试的双语学习材料。

  • 按教材小节展开正文，每节都讲到它该讲的位置。
  • 每个知识块固定包含：中文解释、English term、考试问法、公式/判断规则、陷阱、题库证据。
  • 原来的公式、考点、陷阱不删除，重排进对应知识块和最后的速查区。
Mxx-Module.md 新页面结构
0. Reading Contract 学习契约本模块你最后必须会解释什么、计算什么、判断什么。
1. Module Brief 模块定位LOS、prerequisites、跨科目接口、考试角色。
2. Curriculum Spine 教材正文主线按 2.1 / 2.2 / 3.1 等教材小节逐段重写。
3. Exam Translation 考试翻译把教材每节转成题干触发词、题型、步骤、判断规则。
4. Formula & Decision Bench 公式与决策台公式变量、使用条件、不要用的场景、单位/时点检查。
5. Practice Evidence 题库证据基础题和 mock 按知识块回填：考什么、怎么问、易错口径。
6. Trap Ledger 陷阱账本把常见陷阱按知识块编号，和错题卡/fix rule 对接。
7. Final Recall Sheet 最后回忆页90 秒主动回忆、公式选择、常见误判、next drill。
Knowledge Block

每个知识块的内部模板

块内字段 作用 示例：M01 Rates and Returns
Textbook Position 告诉这个点来自教材哪一节 2.1 Determinants of Interest Rates
Concept in Chinese 用中文讲清真正含义 利率不是单一数字，而是时间价值和不同风险补偿的总和。
English Terms 保留考试识题语言 real risk-free rate, inflation premium, default risk premium, liquidity premium, maturity premium
Exam Translation 把知识点翻译成题目动作 看到 “higher required return” 不能只说 risk higher，要判断是哪一种 premium 变化。
Formula / Rule 公式、口径、限制条件 nominal rate ≈ real risk-free + expected inflation + risk premiums
Practice Evidence 基础题/mock 如何考 题目常给一个情境，让你识别 required return、discount rate 或 opportunity cost。
Trap & Fix Rule 把易错点变成下次动作 不要把所有高利率都归因于 default risk；先逐项排 premium。
Implementation Route

建议实施路线

1. 清理模板痕迹移除或重排机械的 Textbook Signal Topics / 教材驱动补强表格。
2. 建 C+ 模板定义 MOC 和 Module 的新标准结构，保留中英双语。
3. 先做 Quant 样板用 M01 和 MOC 打样，确认阅读体验。
4. 批量扩散脚本按 93 个现役模块重排，不碰 _legacy / _archive。
5. 质量审计检查教材小节覆盖、题库证据回填、双语保留和链接完整性。
