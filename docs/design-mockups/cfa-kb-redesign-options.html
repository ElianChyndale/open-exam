CFA L1 Knowledge Base Redesign Options

目标不是再塞一张“补强表格”，而是把原版教材 Official Curriculum 的结构、LOS、例题逻辑、做题动作自然融入 MOC 和 Module。保留中英双语：中文解释负责理解，English terms 负责识题和精确命名。

Option A

Textbook Walkthrough 教材导读型

每个 Module 按原版教材小节顺序重写。适合“我想像读教材一样学习，但更清楚、更短、更可复习”。

Module Page
1. Why This Module Matters模块在考试和跨科目中的作用
2. Textbook Map按 2.1, 2.2, 3.1 展开教材小节
3. Core Explanations每节中文讲透 + English term
4. Worked Logic教材例题逻辑和变量口径
5. Exam Traps按教材小节归属的陷阱
Option B

Exam Playbook 考试作战型

每个 Module 按题型和答题动作组织。适合“我已经学过，想快速知道题目问什么、怎么做、哪里容易错”。

Module Page
1. Question Triggers题干触发词和 LOS 动词
2. Decision Tree看到条件后选公式/框架
3. Knowledge Capsules每个考点压缩成定义-条件-动作
4. Practice Reflection基础题和 mock 暴露的误区
5. Final Checklist考前 90 秒检查清单
Option C 推荐

Curriculum Playbook 教材作战混合型

上半部分按教材讲清楚，下半部分按考试动作压缩。适合长期维护，也最符合你的“每个知识点讲到该讲的地方”。

Module Page
1. Module Brief定位、LOS、跨科目接口
2. Curriculum Spine教材小节作为主骨架
3. Exam Translation每节转成题型、公式、判断规则
4. Practice Evidence基础题 + mock 回填到对应小节
5. Memory Layer易错、fix rule、next drill
Recommended MOC

MOC 新结构

MOC 应该是“科目地图”，不是正文仓库。它负责告诉你每个 Module 在教材、考试、题库、错题闭环中的位置。

  • 保留官方模块导航，但把“教材锚点表”改成可读的 subject map。
  • 每个 Module 一行包含：教材章节、核心任务、最高频题型、连接到题库和 mock。
  • 新增一页级别的 study route：先学什么、哪些模块一起复盘、哪些跨科目接口要连。

Recommended Module

Module 新结构

Module 页应该像一章“教材驱动的考试笔记”：先讲懂，再翻译成会做题的动作。删除机械的补强表格，把它们融入每个知识点段落。

  • 每个教材小节变成一个知识块，而不是挂在末尾。
  • 每个知识块固定包含：中文解释、English term、公式或判断规则、题干触发词、常见陷阱。
  • 基础题和 mock 不独立漂浮，回填到对应知识块的 “Practice Evidence”。

1. Module Brief
本章解决什么问题 / LOS / exam role / prerequisites.
2. Curriculum Spine
2.1 Determinants of Interest Rates: 中文解释 + required return / discount rate / opportunity cost.
3. Exam Translation
题干出现 HPR, annualized, time-weighted, money-weighted 时，如何选择口径。
4. Formula Bench
公式不再孤立列出，而是带变量口径、使用条件、不要使用的条件。
5. Practice Evidence
基础题和 mock 题按 HPR / mean return / MWRR vs TWRR / fees-tax-leverage 分类。
6. Reflection Hooks
易错点、fix rule、next drill，连接 .system/memory。

方案对比

方案 最适合 优点 代价 我的建议
Option A 教材导读型 第一轮系统学习 最贴原版教材，覆盖感强 做题动作不够突出，复习时偏长 适合作为正文上半部分
Option B 考试作战型 刷题和 mock 前 很快，动作明确 容易牺牲教材小节的完整性 适合作为正文下半部分
Option C 混合型 长期知识库 教材覆盖 + 考试动作 + 错题闭环都能放对位置 重构脚本更复杂，需要分批验证 推荐选这个
