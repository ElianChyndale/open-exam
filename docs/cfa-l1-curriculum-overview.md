## 科目详解

### 01 Quantitative Methods (6-9%)
**核心：将投资问题翻译成统一的计算语言**
| 模块 | 内容 |
|------|------|
| M1: Rates and Returns | HPR, MWRR/TWRR, 年化收益率, 连续复利 |
| M2: Time Value of Money in Finance | PV/FV, 年金, 永续年金, 现金流可加性 |
| M3: Statistical Measures of Asset Returns | 集中趋势, 离散度, 偏度, 峰度, 相关性 |
| M4: Probability Trees & Conditional Expectations | 期望值, 概率树, 贝叶斯公式 |
| M5: Portfolio Mathematics | 组合期望/方差, 协方差, 短缺风险 |
| M6: Simulation Methods | 对数正态分布, 蒙特卡洛, 自助法 |
| M7: Estimation and Inference | 抽样方法, CLT, 标准误, 重抽样 |
| M8: Hypothesis Testing | H0/H1, Type I/II, 检验力 |
| M9: Tests of Independence | 相关检验, 列联表 |
| M10: Simple Linear Regression | 模型设定, 诊断, 拟合, 预测 |
| M11: Big Data Techniques | Fintech, AI/ML, 数据科学 |

### 02 Economics (6-10%)
**核心：宏观与微观经济分析对投资的影响**
| 模块 | 内容 |
|------|------|
| M1: The Firm and Market Structures | 市场结构, 供需分析 |
| M2: Understanding Business Cycles | 经济周期, 领先/同步/滞后指标 |
| M3: Fiscal Policy | 财政政策, 乘数效应, 政府预算 |
| M4: Monetary Policy | 货币政策, 利率传导, 通胀目标 |
| M5: Introduction to Geopolitics | 地缘政治风险, 投资影响 |
| M6: International Trade | 贸易理论, 比较优势, 贸易壁垒 |
| M7: Capital Flows and FX | 国际收支, 汇率制度 |
| M8: Exchange Rate Calculations | 交叉汇率, 远期汇率, PPP |

### 03 Corporate Issuers (10-15%)
**核心：公司决策与治理如何影响投资价值**
| 模块 | 内容 |
|------|------|
| M1: Organizational Forms & Ownership | 公司结构, 所有权类型 |
| M2: Investors and Other Stakeholders | 投资者类型, 利益相关者 |
| M3: Corporate Governance | 治理机制, 董事会, 风险管理 |
| M4: Working Capital and Liquidity | 流动性管理, 现金转换周期 |
| M5: Capital Investments & Allocation | 资本预算, NPV/IRR, 项目评估 |
| M6: Capital Structure | 债务/权益融资, 杠杆, WACC |
| M7: Business Models | 商业模式, 价值创造 |

### 04 Financial Statement Analysis (13-17%)
**核心：读懂财务报表，识别会计质量**
| 模块 | 内容 |
|------|------|
| M1: Introduction to FSA | 报表框架, IFRS vs US GAAP |
| M2: Analyzing Income Statements | 收入确认, 费用匹配, EPS |
| M3: Analyzing Balance Sheets | 资产负债分类, 计量基础 |
| M4: Cash Flows I | 间接法, 经营活动现金流 |
| M5: Cash Flows II | FCFF, FCFE, 现金流比率 |
| M6: Analysis of Inventories | 成本流转 FIFO/LIFO, 减值 |
| M7: Analysis of Long-Term Assets | 资本化, 折旧, 摊销, 减值 |
| M8: Long-Term Liabilities & Equity | 债券, 租赁, 养老金, 递延税 |
| M9: Analysis of Income Taxes | DTA/DTL, 永久/暂时性差异 |
| M10: Financial Reporting Quality | 盈余质量, 预警信号 |
| M11: Financial Analysis Techniques | 比率分析, DuPont, 同型分析 |
| M12: Financial Statement Modeling | 预测, 敏感性分析 |

### 05 Equity (10-15%)
**核心：股票市场结构、分析和估值**
| 模块 | 内容 |
|------|------|
| M1: Market Organization & Structure | 一级/二级市场, 交易机制 |
| M2: Security Market Indexes | 指数构建方法 |
| M3: Market Efficiency | EMH, 异象, 行为金融 |
| M4: Overview of Equity Securities | 普通/优先股, ADR, ETF |
| M5: Company Analysis: Past & Present | 历史报表分析, 比率 |
| M6: Industry & Competitive Analysis | 波特五力, 行业生命周期 |
| M7: Company Analysis: Forecasting | 收入预测, 估值输入 |
| M8: Equity Valuation | DDM, FCF, 市盈率/市净率 |

### 06 Fixed Income (10-15%)
**核心：固定收益工具定价与风险分析**
| 模块 | 内容 |
|------|------|
| M1-M2: Instrument Features & Cash Flows | 债券条款, 息票结构 |
| M3-M5: Markets | 发行/交易, 公司债市场, 政府债市场 |
| M6: Valuation | 价格-收益率关系, 贴现 |
| M7-M8: Yield Measures | YTM, 当前收益率, 浮动利率利差 |
| M9: Term Structure | 即期/远期利率, 收益率曲线 |
| M10-M12: Risk | 久期, 凸性, 利率风险 |
| M13-M14: Credit | 信用风险, 评级, 利差 |
| M17-M19: Securitization | ABS, MBS, CDO |

### 07 Derivatives (6-9%)
**核心：衍生品定价与对冲应用**
| 模块 | 内容 |
|------|------|
| M1-M3: Features & Uses | 衍生品类型, 用途, 风险 |
| M4: Arbitrage & Replication | 一价定律, 持有成本 |
| M5-M7: Pricing | 远期, 期货, 互换定价 |
| M8-M9: Options | 期权定价, 看跌看涨平价 |
| M10: Binomial Model | 一期二叉树 |

### 08 Alternative Investments (7-10%)
**核心：另类投资特征与绩效评估**
| 模块 | 内容 |

| M2: Performance | IRR, TVPI, DPI, RVPI |
| M3: Private Capital | VC, LBO, 私募信贷 |
| M4: Real Assets | 房地产, 基础设施 |
| M5: Natural Resources | 大宗商品, 资源 |
| M6: Hedge Funds | 策略, 费用 |
| M7: Digital Assets | 加密货币, 区块链 |

### 09 Portfolio Management (11-15%)
**核心：组合构建理论与风险管理**
| 模块 | 内容 |
|------|------|
| M1: Risk-Return I | 有效前沿, 分散化 |
| M2: Risk-Return II | CAPM, 贝塔, SML |
| M3: PM Overview | 集合投资, ETF, 共同基金 |
| M4: Planning & Construction | IPS, 资产配置 |
| M5: Behavioral Biases | 认知/情绪偏差 |
| M6: Risk Management | VaR, 压力测试 |

### 10 Ethical and Professional Standards (15-20%)
**核心：职业道德与专业行为准则**
| 模块 | 内容 |
|------|------|
| M1: Ethics & Trust | 道德决策框架 |
| M2: Code of Ethics | 七大准则总览 |
| M3: Standards I-VII | 专业、诚信、对客户/雇主义务、利益冲突 |
| M4: GIPS | 全球投资绩效标准 |
| M5: Ethics Application | 案例研究 |
