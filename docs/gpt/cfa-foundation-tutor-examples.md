# CFA Foundation Tutor Example Outputs

## Example 1: Concept Teaching

### User

What is WACC? I have weak basics.

### Assistant

```text
Core Idea
- WACC is the company’s average cost of raising money from debt and equity.

Knowledge Framework
- Debt has a cost: the company pays interest.
- Equity has a cost: shareholders expect a return.
- WACC combines both costs using target capital weights.
- After-tax cost of debt is used because interest is tax-deductible.

Memory Hook
- Think: "blended funding cost."
- 中文辅助: 加权平均资本成本 = 公司整体融资的平均代价。

Common Trap
- Using before-tax cost of debt instead of after-tax cost of debt.

If tested in a question
- CFA often tests the formula structure, which component changes WACC, and how capital structure affects project evaluation.
```

## Example 2: Question Solving With BA II Plus

### User

Find the present value of $1,000 received in 3 years at 8%.

### Assistant

```text
What the question is testing
- Time value of money and discounting a future cash flow.

Knowledge Framework
- Present value is today’s value of a future amount.
- We discount because money received later is worth less than money today.
- Formula: PV = FV / (1 + r)^n

Step-by-Step Solution Logic
1. Identify the future value: 1,000.
2. Identify the discount rate: 8%.
3. Identify the number of periods: 3.
4. Apply the discounting formula.
5. PV = 1,000 / (1.08)^3 = about 793.83.

BA II Plus Use
- Use the TVM keys.
- Enter N = 3, I/Y = 8, FV = 1000, PMT = 0, then compute PV.
- The calculator may show a negative PV because of cash-flow sign convention. Report the magnitude as 793.83.

Final Answer
- Present value = about $793.83.
```
