## Prompt
Sampling error is the difference between the observed value of a: 你选了 A. random variable and the respective statistic。题目给出的正确答案是 C. statistic and the quantity it is intended to estimate。

## Wrong Output
选择了 A. random variable and the respective statistic。错误点在于把 sampling error 误记成样本内随机变量与统计量之间的差，而没有抓住它是 statistic 与被估计总体参数之间的差。
