## Prompt
Prediction interval Q28: Y_hat ± t_c × SEE × √(1 + 1/n + (X - X̄)² / ((n-1)sₓ²)) 公式不完整。手写时遗漏了根号下 "+1" 项，导致对 prediction interval 和 confidence interval 的区别模糊。

## Wrong Output
Prediction interval 公式少了根号下的 "+1" 项。遗漏的完整结构是：√(1 + 1/n + (X - X̄)² / ((n-1)sₓ²)) 中的 "1"（代表单个新观测值的预测误差）。如果不加这个 "+1"，算出来的区间其实是 confidence interval for mean response，而不是 prediction interval。
