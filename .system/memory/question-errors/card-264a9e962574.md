## Prompt
关于偏度图/分布图的基础识别：你把图的 y 轴记错了。这里应当记住，偏度相关分布图中 y 轴表示 frequency（频率），x 轴才是 return / outcome / value 的分布位置。

## Wrong Output
把偏度图的 y 轴记成了别的含义，而不是 frequency（频率）。
