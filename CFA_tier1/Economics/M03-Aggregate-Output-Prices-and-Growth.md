# M03: Aggregate Output, Prices, and Growth（总产出、价格与增长）

## 1. 核心知识点（中英双语讲解）

### GDP的衡量（Measuring GDP）

**GDP（Gross Domestic Product）**：一国境内在一定时期内生产的最终商品和服务的市场价值。

**三种核算方法（Three Approaches）**：
1. **支出法（Expenditure Approach）**：`GDP = C + I + G + (X − M)`
   - C = 个人消费支出（consumption）
   - I = 国内私人投资（investment），包括固定投资和存货投资
   - G = 政府消费支出和总投资（government spending）
   - X − M = 净出口（net exports）
2. **生产法/增加值法（Value-Added Approach）**：各生产环节增加值之和
3. **收入法（Income Approach）**：各生产要素收入之和（工资+租金+利息+利润）

**名义GDP与实际GDP（Nominal vs Real GDP）**：
- **名义GDP**：按当期价格计算，增长可能是价格上涨或产量增加所致
- **实际GDP**：按基期价格计算，反映真实产出变化

**GDP平减指数（GDP Deflator）**：`GDP Deflator = (Nominal GDP / Real GDP) × 100`
- 衡量整体价格水平变化的综合指标
- 与CPI不同：GDP平减指数包含所有国内生产的商品和服务，不包含进口品

### 通胀与通缩（Inflation and Deflation）

**通胀（Inflation）**：价格水平持续上升。**通缩（Deflation）**：价格水平持续下降。**反通胀（Disinflation）**：通胀率下降但仍为正。

**衡量通胀的指标**：
- **CPI（消费者价格指数）**：一篮子固定消费品价格变化
- **生产者价格指数（PPI）**：批发环节价格变化，通常是CPI的领先指标

### 失业类型（Types of Unemployment）

- **摩擦性失业（Frictional Unemployment）**：换工作间隙的正常失业
- **结构性失业（Structural Unemployment）**：技能与岗位不匹配
- **周期性失业（Cyclical Unemployment）**：由经济周期波动引起

**自然失业率（Natural Rate of Unemployment）** = 摩擦性失业 + 结构性失业。实际失业率 = 自然失业率 → 充分就业（full employment）。

**产出缺口（Output Gap）**：`Output Gap = Actual GDP − Potential GDP`
- 正缺口 → 经济过热（inflationary压力）
- 负缺口 → 经济衰退（recessionary压力）

### 经济增长来源（Sources of Economic Growth）

经济增长 = 劳动投入增长 + 资本投入增长 + 全要素生产率（TFP）增长

- **劳动（Labor）**：劳动力数量和质量的增长
- **资本（Capital）**：实物资本（机器设备、基础设施）的积累
- **全要素生产率（Total Factor Productivity, TFP）**：技术和效率的提升

### 实际利率与名义利率（Real vs Nominal Interest Rate）

**费雪等式（Fisher Equation）**：
- 精确形式：`(1 + r_nominal) = (1 + r_real)(1 + inflation)`
- 近似形式：`r_real ≈ r_nominal − inflation`

## 2. 关键公式（公式+解释+场景）

**GDP支出恒等式**：`GDP = C + I + G + (X − M)`
- 场景：给定各组成部分的变化，判断GDP的变动方向。如C和I上升而G下降，总效应取决于相对变化量。

**GDP平减指数**：`GDP Deflator = (Nominal GDP / Real GDP) × 100`
- 场景：已知名义GDP和实际GDP计算通胀水平。例如Nominal GDP = 11万亿，Real GDP = 10万亿，平减指数 = 110。

**通胀率计算**：`Inflation Rate = (CPI_t / CPI_{t-1}) − 1`
- 场景：计算年度通胀率。CPI从120升至126，则通胀率 = 5%。

**费雪等式精确形式**：`(1 + r_nominal) = (1 + r_real)(1 + inflation)`
- 场景：名义利率5%，通胀2%，则实际利率 = (1.05/1.02) − 1 ≈ 2.94%。

## 3. 常见考点与解题思路

**考点1：GDP核算中的包含与排除**
- 只计算最终商品（final goods），不计算中间品（intermediate goods）
- 只计算国内生产（geographic boundary），不区分本国人还是外国人生产
- 二手房交易不计入GDP（但经纪服务费计入）

**考点2：名义GDP与实际GDP的转换**
- 实际GDP = 名义GDP / 价格指数 × 100
- 比较不同年份实际GDP才能说明经济真实增长

**考点3：产出缺口判断**
- 实际GDP > 潜在GDP → 通胀压力 → 央行可能紧缩
- 实际GDP < 潜在GDP → 通缩压力 → 央行可能宽松

## 4. 易错点提醒

- **GDP是流量（flow）不是存量（stock）**：衡量一定时期内的生产，不是累积财富。
- **GDP不包括非市场活动**：如家务劳动、地下经济。
- **CPI存在替代偏差（substitution bias）**：当价格上涨时，消费者转向更便宜的商品，CPI可能高估实际通胀。
- **实际利率一定要用通胀调整**：比较不同时期利率时必须使用实际利率。
