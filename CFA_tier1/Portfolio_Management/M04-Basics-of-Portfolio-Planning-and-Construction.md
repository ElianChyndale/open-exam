# M04: Basics of Portfolio Planning and Construction

## 0. Reading Contract 阅读契约

- **Official spine**：IPS, risk and return objectives, constraints, client information, capital market expectations, strategic asset allocation, construction principles, ESG.
- **LOS contract**：describe IPS reasons/components; describe risk/return objectives; explain willingness vs ability; describe constraints; explain asset-class specification; describe construction and ESG integration.
- **Evidence rule**：错题标 `return_objective`, `risk_objective`, `willingness_ability`, `constraint_lttlu`, `asset_allocation`, or `esg`。

## 1. Module Brief 模块定位

IPS questions are client-fact translation tasks. 本模块核心是把事实放入 objectives and constraints，并用 strategic asset allocation 连接 portfolio construction。

## 2. Curriculum Spine 教材主线

| Spine | English trigger | 中文任务 |
|---|---|---|
| IPS purpose | written policy, discipline, communication | 说明为什么需要书面 IPS。 |
| Return objective | required return, spending, liabilities, inflation | 写具体 required return，不写空话。 |
| Risk objective | willingness, ability/capacity, tolerance | 冲突时通常以 ability 为硬约束。 |
| Constraints | liquidity, time horizon, taxes, legal/regulatory, unique | 分类客户事实。 |
| Asset allocation | strategic allocation, asset classes, capital market expectations | 将 IPS 转成配置。 |
| ESG | constraints, values, risks, opportunities | 依据题干决定放入哪里。 |

## 3. Exam Translation 考试翻译

1. Return objective：问 “需要赚多少以及为什么”。
2. Risk objective：分别判断 ability and willingness。
3. Constraints 用 `L-T-T-L-U`，不要把 concentrated position 全写成 risk objective。
4. Asset allocation 先 strategic，再 tactical/security selection。

## 4. Formula & Decision Bench 公式与决策台

| Item | Formula / rule | Use |
|---|---|---|
| Required nominal return | spending/liability need + inflation + fees/taxes where relevant | Return objective. |
| Risk tolerance | ability/capacity plus willingness | Risk objective. |
| Conflict rule | low ability generally overrides high willingness | Suitability. |
| L-T-T-L-U | liquidity, time horizon, taxes, legal/regulatory, unique circumstances | Constraint classification. |
| Strategic asset allocation | long-term target weights by asset class | Main driver of portfolio risk/return. |

## 5. Practice & Mock Evidence 题库证据

- Track `objective_constraint_mix` when a constraint is written as objective.
- Track `ability_willingness_conflict` when willingness overrides insufficient capacity.
- Track `liquidity_need` when near-term cash need is ignored.
- Track `esg_placement` when ESG is included without evidence from mandate or client preference.

## 6. Trap Ledger 陷阱账本

| Trap | Fix rule |
|---|---|
| Return objective = maximize return | It must state required return and purpose. |
| High willingness means high risk portfolio | Ability/capacity is the hard suitability limit. |
| Time horizon is always one period | Investors can have multiple horizons. |
| ESG always belongs in unique circumstances | It depends on mandate: value, risk, return or constraint. |

## 7. Final Recall Sheet 最终回忆单

- IPS = objectives + constraints + allocation + review discipline.
- Objectives: return and risk.
- Risk = ability plus willingness; conflict -> capacity dominates.
- Constraints = L-T-T-L-U.
- Strategic asset allocation precedes security selection.
