# M04: 市场有效性与组合构建 (Market Efficiency and Portfolio Construction)

## 1. 核心知识点 (Core Knowledge Points)

### 1.1 市场有效性假说 (Efficient Market Hypothesis, EMH)

- **弱式有效 (Weak-form efficiency)**：当前价格反映所有历史价格和交易量信息
  - 技术分析无法持续获得超额收益
  - 随机游走 (random walk) 模式

- **半强式有效 (Semi-strong form efficiency)**：当前价格反映所有公开信息
  - 基本面分析无法持续获得超额收益
  - 信息公布后价格快速调整

- **强式有效 (Strong-form efficiency)**：当前价格反映所有信息（包括内幕信息）
  - 即使内幕信息也无法获得超额收益
  - 在实际市场中极少成立

- **市场有效性对投资的含义**：
  - 市场越有效，被动管理 (passive management) 越合理
  - 市场越无效，主动管理 (active management) 越有机会

### 1.2 主动 vs 被动管理 (Active vs Passive Management)

- **主动管理 (active management)**：
  - 通过选股 (security selection) 和市场时机 (market timing) 追求超额收益 (alpha)
  - 费用较高，交易成本高
  - 需要在有信息优势 (edge) 且有成本优势时才值得

- **被动管理 (passive management)**：
  - 跟踪指数，获取市场收益 (beta)
  - 费用低，透明度高，税收效率高
  - 适合有效市场或缺乏显著信息优势时

- **主动/被动选择决策框架**：
  - 依赖市场效率程度
  - 考虑信息优势、交易成本、税收、投资者目标

### 1.3 组合构建流程 (Portfolio Construction Process)

1. **目标设定 (Planning/Objectives)**：确定收益目标和风险目标
2. **约束分析 (Constraints)**：流动性、时间跨度、税收、法律、特殊情形
3. **资产配置 (Asset Allocation)**：战略性配置主导组合风险
4. **执行 (Implementation)**：选具体证券，主动或被动方式
5. **监控与调整 (Monitoring & Rebalancing)**：回顾并调整

### 1.4 战略与战术资产配置 (Strategic vs Tactical Allocation)

- **战略资产配置 (Strategic Asset Allocation, SAA)**：
  - 长期政策组合 (policy portfolio)
  - 决定组合绝大部分的收益波动
  - 围绕 SAA 的偏差构成"政策风险预算"

- **战术资产配置 (Tactical Asset Allocation, TAA)**：
  - 短期系统性偏离 SAA
  - 目的是利用市场短期定价偏差
  - 必须有预算约束和风险控制

### 1.5 风险预算 (Risk Budgeting)

- 将总风险分解到不同资产类别/策略
- 明确分配"主动风险预算" (active risk budget)
- 确保主动风险不超出投资者承受范围

## 2. 关键公式 (Key Formulas)

| 指标 | 公式/概念 | 说明 |
|------|-----------|------|
| 主动收益 (Active return) | `Rp - Rb` | 组合超基准收益 |
| 主动风险 (Active risk / Tracking error) | `σ(Rp - Rb)` | 跟踪误差 |
| 信息比率 (Information ratio) | `(Rp-Rb) / σ(Rp-Rb)` | 单位主动风险创造的主动收益 |
| 政策风险预算 | SAA 的偏离范围 | 限定战术调整的幅度 |

*注：M04 多以概念题出现，计算题较少。*

## 3. 常见考点与解题思路 (Exam Tips & Approaches)

### 考点1：判断市场有效性形式
- **步骤**：给一个市场现象 → 判断属于哪种有效性形式
- 常见题型：给定测试结果（如技术分析能否获利）→ 判断支持/反驳哪种形式

### 考点2：主动 vs 被动选择
- **步骤**：分析市场特征（效率程度、交易成本、投资者知识）→ 判断选择
- 常见陷阱：不会自动选择主动管理，即使市场稍微无效也需要成本优势

### 考点3：组合构建流程排序
- **步骤**：给一系列步骤 → 按正确流程排序
- 常见题型：目标 → 约束 → 资产配置 → 执行 → 回顾

### 考点4：战略 vs 战术配置
- **步骤**：判断某一投资行为属于战略还是战术
- 关键：战略性是长期政策决定，战术性是短期偏离

## 4. 易错点提醒 (Common Mistakes)

| 错误理解 | 正确理解 |
|----------|----------|
| 市场无效就一定选主动管理 | 还需要考虑信息优势、成本、税收 |
| 被动管理 = 不需要判断 | 仍要选择合适基准、考虑成本和税收 |
| 战术配置就是随意调整 | TAA 需要有系统性框架和风险预算 |
| 组合风险主要来自选股 | 战略资产配置决定组合 90%+ 的风险收益波动 |
| 主动管理 = 更专业 | 主动管理只是更主动承担跟踪风险 |
| 市场有效 = 没有交易理由 | 有效市场中仍有配置需求和流动性需求 |
