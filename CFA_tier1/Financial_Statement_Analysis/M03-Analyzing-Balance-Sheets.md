# M03: Analyzing Balance Sheets

> **模块定位 Module role**: explain how recognition and measurement of assets/liabilities change comparability, leverage, liquidity, and future earnings.

## 0. Reading Contract 阅读契约

**Official module**: Module 3: Analyzing Balance Sheets
**Exam task**: explain reporting/disclosures for intangible assets, goodwill, financial instruments, non-current liabilities, and calculate/interpret common-size balance sheets and related ratios.

Learning outcome actions:

- Explain financial reporting and disclosures for intangible assets.
- Explain financial reporting and disclosures for goodwill.
- Explain reporting and disclosures for financial instruments.
- Explain reporting and disclosures for non-current liabilities.
- Calculate and interpret common-size balance sheets and balance-sheet ratios.

## 1. Module Brief 模块定位

Balance sheet analysis is about **what is recognized, how it is measured, and what is missing from the face of the statements**. The exam often asks you to translate accounting classification into assets, liabilities, equity, leverage, and turnover.

Core English anchors: intangible assets, identifiable intangibles, goodwill, impairment, financial instruments, fair value, amortized cost, non-current liabilities, deferred tax liabilities, common-size balance sheet.

## 2. Curriculum Spine 教材主线

1. **Intangible assets**: identifiable intangibles and disclosure.
2. **Goodwill**: created in business combinations; impairment-focused analysis.
3. **Financial instruments**: classification and measurement determine where gains/losses appear.
4. **Non-current liabilities**: long-term financial liabilities and deferred tax liabilities.
5. **Ratios/common-size**: each balance sheet line item over total assets; liquidity, leverage, and structure analysis.

## 3. Exam Translation 考试翻译

| Prompt Signal | Translate To | Answer Move |
|---|---|---|
| Internally generated intangible | recognition restriction | Usually expensed; IFRS development may be capitalized if criteria met |
| Purchased intangible | identifiable asset | Capitalize and amortize if finite-lived |
| Goodwill impairment | quality and asset write-down | Reduce assets/equity/NI; no amortization |
| Financial instrument fair value | measurement/classification | Determine whether gain/loss affects income or equity |
| Common-size balance sheet | structure analysis | Each item divided by total assets |

## 4. Formula & Decision Bench 公式与判断台

| Formula / Framework | Use |
|---|---|
| Common-size balance sheet item = line item / total assets | Compare asset/liability structure across firms |
| Current ratio = current assets / current liabilities | Short-term liquidity |
| Quick ratio = (cash + marketable securities + receivables) / current liabilities | More conservative liquidity |
| Debt-to-equity = total debt / total equity | Leverage |
| Financial leverage = average total assets / average total equity | DuPont leverage input |
| Goodwill impairment effect | Assets down, equity down, NI down; CFO unaffected except tax unless stated |

Decision bench: for any balance-sheet accounting choice, answer in the order **asset/liability -> equity -> income -> ratios**.

## 6. Trap Ledger 易错账本

| Trap | Fix Rule |
|---|---|
| Goodwill amortization assumed | Goodwill is tested for impairment, not amortized |
| Internally generated brand capitalized automatically | Most internally generated intangibles are expensed |
| Ratio effect stops at balance sheet | Carry through NI and future expense effects when relevant |
| Common-size denominator wrong | Balance sheet common-size uses total assets |
| DTL treated as operating debt without context | Classify carefully; analyze reversal and tax-rate assumptions |

## 7. Final Recall Sheet 终局速记

- Purchased identifiable intangibles are recognized; internally generated intangibles are restricted.
- Goodwill arises only in business combinations and is impairment-tested.
- Financial instrument classification determines measurement and gain/loss location.
- Common-size balance sheet = every line / total assets.
- Always translate recognition into ratios: liquidity, leverage, turnover, ROA/ROE.
