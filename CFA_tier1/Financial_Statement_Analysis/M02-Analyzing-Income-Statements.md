# M02: Analyzing Income Statements

> **模块定位 Module role**: turn accrual earnings into normalized performance evidence: revenue timing, expense timing, non-recurring items, EPS, and margin analysis.

## 0. Reading Contract 阅读契约

**Official module**: Module 2: Analyzing Income Statements
**Exam task**: describe and interpret revenue recognition, expense recognition, non-recurring items, EPS/diluted EPS, and income-statement ratios/common-size analysis.

Learning outcome actions:

- Describe general revenue recognition principles and specific applications.
- Contrast expensing versus capitalization and explain analyst implications.
- Identify non-recurring items, discontinued operations, accounting policy changes, changes in scope, and exchange-rate effects.
- Calculate and interpret basic EPS and diluted EPS, including complex capital structures and antidilutive securities.
- Evaluate performance using common-size income statements and income-statement ratios.

## 1. Module Brief 模块定位

Income statement questions ask whether reported profit is **timely, comparable, persistent, and attributable to common shareholders**. Most traps come from timing: revenue too early/late, expense capitalized/expensed, one-off item included in trend, or potential shares treated incorrectly in diluted EPS.

Core English anchors: revenue recognition, performance obligations, transaction price, expense matching, capitalization, non-recurring items, discontinued operations, basic EPS, diluted EPS, antidilutive, common-size income statement, gross/operating/net margin.

## 2. Curriculum Spine 教材主线

1. **Revenue recognition**: general principles and standards; five-step model.
2. **Expense recognition**: matching principle, period costs, capitalization versus expensing, interest and development costs.
3. **Non-recurring items**: unusual/infrequent items, discontinued operations, accounting policy changes, scope and FX changes.
4. **EPS**: simple vs complex capital structure, basic EPS, if-converted method, treasury stock method, antidilutive exclusion.
5. **Performance analysis**: common-size income statements and income-statement ratios.

## 3. Exam Translation 考试翻译

| Prompt Signal | Translate To | Answer Move |
|---|---|---|
| Multiple deliverables, contract, obligation | revenue recognition | Apply five steps; identify timing and allocation |
| "capitalize instead of expense" | earnings and asset timing | Current NI/assets/equity higher; future depreciation/amortization higher |
| Discontinued, unusual, policy change | normalized earnings | Remove or isolate for sustainable earnings analysis |
| Convertible debt/preferred | diluted EPS if-converted | Add back after-tax interest or preferred dividends; add shares |
| Options/warrants | treasury stock method | Include incremental shares only if dilutive |
| Common-size income statement | margin diagnosis | Each line divided by revenue |

## 4. Formula & Decision Bench 公式与判断台

| Formula / Framework | Use |
|---|---|
| Revenue five-step model: contract -> obligations -> transaction price -> allocation -> recognition | Determine when and how much revenue is recognized |
| Basic EPS = `(NI - preferred dividends) / weighted-average common shares` | Simple capital structure or baseline EPS |
| If-converted convertible preferred | Numerator add preferred dividends; denominator add converted common shares |
| If-converted convertible debt | Numerator add after-tax interest; denominator add conversion shares |
| Treasury stock method | Incremental shares = shares issued - shares repurchased with assumed proceeds |
| Diluted EPS rule | Include only securities that reduce EPS; exclude antidilutive securities |
| Gross margin = gross profit / revenue | Production/pricing/cost signal |
| Operating margin = operating income / revenue | Core operating profitability |
| Net margin = net income / revenue | After-tax total profitability |

Decision bench: If a choice affects recognition timing, separate **current-period effect** from **future-period reversal**.

## 6. Trap Ledger 易错账本

| Trap | Fix Rule |
|---|---|
| Diluted EPS higher than basic EPS | Exclude antidilutive securities; diluted EPS cannot improve EPS |
| Forget after-tax interest in convertible debt | Add back interest net of tax to numerator |
| Treat all unusual items as discontinued operations | Discontinued operations require disposal/held-for-sale component logic |
| Capitalization effect only stated for NI | Also state asset, equity, future expense, ROA/turnover effects |
| Common-size denominator wrong | Income statement common-size uses revenue |

## 7. Final Recall Sheet 终局速记

- Five-step revenue model: contract, obligations, price, allocation, recognition.
- Capitalize now -> current expense lower, NI/assets/equity higher, future expense higher.
- Normalize earnings by isolating non-recurring items and policy/scope/FX effects.
- Basic EPS starts with income available to common shareholders.
- Diluted EPS includes only dilutive convertibles/options/warrants.
