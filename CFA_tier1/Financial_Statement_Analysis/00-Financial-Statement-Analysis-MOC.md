# Financial Statement Analysis MOC

> **一句话核心**：把三张报表转成可比较、可预测、可质疑的经营证据。

---

## 1. 科目定位

- **考试权重**：11-14%
- **官方模块数**：12
- **主线框架**：定位报表项目 -> 调整可比性 -> 计算指标 -> 解释质量与持续性
- **使用方式**：先从官方模块导航进入，再用编号知识树做主动回忆，最后用公式/陷阱清单做考前压缩。

## 3. 核心知识树

```text
Financial Statement Analysis (11-14%)
├─ 1. Introduction to Financial Statement Analysis
│  ├─ 1.1 Introduction
│  │  ├─ 定位：FSA 的输出不是报表复述，而是 investment decision inputs
│  │  └─ 判断：题干问 source / role / limitation 时先回到 purpose and context
│  ├─ 1.2 Financial Statement Analysis Framework
│  │  ├─ 六步：purpose -> collect -> process -> analyze -> conclusions -> update
│  │  └─ 考试判断：任何建议题都要说明数据来源、可比性限制和更新触发
│  ├─ 1.3 Scope of Financial Statement Analysis
│  │  ├─ 信息层级：statements / notes / MD&A / audit / regulatory filings / external sources
│  │  └─ 限制：审计意见提供 assurance，不替代分析师判断
├─ 2. Analyzing Income Statements
│  ├─ 2.1 收入确认 (Revenue Recognition)
│  │  ├─ 五步：contract -> obligations -> transaction price -> allocation -> control transfer
│  │  └─ 判断：提前确认收入会提高当期 revenue、margin、assets，并压低未来 growth quality
│  ├─ 2.2 费用确认 (Expense Recognition)
│  │  ├─ matching principle；capitalize shifts expense timing, not economics
│  │  └─ 资本化前期：NI/Equity/Assets 偏高，后期 depreciation/amortization 压利润
│  ├─ 2.3 非常项目与政策变更 (Unusual Items and Policy Changes)
│  │  ├─ discontinued operations 要与 continuing operations 分开
│  │  └─ 政策变更常用 retrospective application；估计变更通常 prospective
│  ├─ 2.4 EPS：Basic EPS 与 Diluted EPS；先排除 antidilutive securities
│  └─ 2.5 Common-size IS：所有项目 / revenue，连接 margin trend 与质量分析
├─ 3. Analyzing Balance Sheets
│  ├─ 3.1 无形资产 (Intangible Assets)
│  │  ├─ purchased 可资本化；internally generated 在 US GAAP 多费用化，IFRS development 可有条件资本化
│  │  └─ finite life amortize；indefinite life impairment test
│  ├─ 3.2 商誉 (Goodwill)
│  │  ├─ Goodwill = purchase price - fair value of identifiable net assets
│  │  └─ 不系统摊销；impairment 是盈利质量和并购假设失败信号
│  ├─ 3.3 金融工具与非流动负债 (Financial Instruments and Non-Current Liabilities)
│  │  ├─ amortized cost / FVOCI / FVTPL 决定 fair value changes 进 OCI 还是 income
│  │  └─ current vs non-current classification 改变 liquidity ratios
│  └─ 3.4 Common-size BS：所有项目 / total assets，读资产结构、资本结构、营运资本
├─ 4. Analyzing Statements of Cash Flows I
│  ├─ 4.1 三大报表联动 (Three-Statement Linkage)
│  │  ├─ IS 提供 NI；BS 提供 working capital changes；SCF 解释 cash movement
│  │  └─ CFO/CFI/CFF 分类回答“现金从哪里来、用到哪里去”
│  ├─ 4.2 直接法与间接法编制 (Direct vs Indirect Preparation)
│  │  ├─ Indirect CFO = NI + noncash charges - noncash gains/losses ± WC changes
│  │  └─ Direct method 用 revenue/expense 与相关 BS 账户倒推 cash receipts/payments
│  ├─ 4.3 IFRS vs US GAAP 现金流分类差异 (Cash Flow Classification)
│  │  └─ 利息、股利、银行透支分类差异常考；CFO 数字可比性要先调整
├─ 5. Analyzing Statements of Cash Flows II
│  ├─ 5.1 报告式与同比例现金流量表 (Reported vs Common-Size Cash Flow Statements)
│  │  └─ 看 CFO、CFI、CFF 的结构和可持续来源，不只看总现金增加
│  ├─ 5.2 自由现金流 (Free Cash Flow)
│  │  ├─ FCFF = CFO + Interest(1 - T) - FCInv，给所有资本提供者
│  │  └─ FCFE = CFO - FCInv + Net Borrowing，给普通股股东
│  ├─ 5.3 现金流比率分析 (Cash Flow Ratio Analysis)
│  │  └─ performance ratios 看现金创造；coverage ratios 看债务/利息覆盖
├─ 6. Analysis of Inventories
│  ├─ 6.1 计量基础 (Measurement Basis)
│  │  ├─ lower of cost and NRV；write-down 降低 inventory/assets/NI，通常提高 turnover
│  │  └─ IFRS 允许有限转回，US GAAP 通常不允许
│  ├─ 6.2 成本流转方法 (Cost-Flow Methods)
│  │  ├─ 通胀：FIFO COGS 低、NI 高、inventory 高、tax 高；LIFO 相反且 CFO 更高
│  │  └─ LIFO reserve 用于把 LIFO 公司调到 FIFO 可比口径
│  ├─ 6.3 存货披露与分析师检查点 (Inventory Disclosures and Analyst Checks)
│  │  └─ inventory growth > sales growth、LIFO liquidation、obsolete inventory 是质量信号
├─ 7. Analysis of Long-Term Assets
│  ├─ 7.1 无形资产来源 (Intangible Asset Origin)
│  │  └─ purchased / internally developed / business combination 三类来源决定确认基础
│  ├─ 7.2 PP&E 与无形资产减值/终止确认 (PP&E and Intangible Impairment / Derecognition)
│  │  ├─ Carrying amount = cost - accumulated depreciation/amortization - impairment
│  │  └─ sale gain/loss = proceeds - carrying amount；depreciation 是 noncash charge
│  ├─ 7.3 披露分析 (Disclosure Analysis)
│  │  └─ useful life、residual value、depreciation method 改变 NI、assets、ROA/ROE
├─ 8. Topics in Long-Term Liabilities and Equity
│  ├─ 8.1 租赁会计：出租人与承租人 (Lease Reporting: Lessor vs Lessee)
│  │  ├─ lessee 确认 ROU asset 和 lease liability；finance lease 前期费用更高
│  │  └─ classification 改变 leverage、asset turnover、interest coverage
│  ├─ 8.2 确定缴费 vs 确定给付计划 (Defined Contribution vs Defined Benefit Plans)
│  │  ├─ DC：雇主缴费即费用；DB：PBO 与 plan assets 形成 funded status
│  │  └─ discount rate 等假设影响 PBO 和 pension cost
│  ├─ 8.3 股权激励薪酬 (Stock-Based Compensation)
│  │  └─ grant-date fair value 在 vesting period 费用化；noncash 但稀释 EPS
├─ 9. Analysis of Income Taxes
│  ├─ 9.1 会计利润 vs 应税所得 (Accounting Profit vs Taxable Income)
│  │  ├─ taxes payable 基于 taxable income；tax expense 基于 financial reporting
│  │  └─ temporary differences 未来转回；permanent differences 只影响 ETR
│  ├─ 9.2 递延所得税资产与负债 (Deferred Tax Assets and Liabilities)
│  │  ├─ DTL：现在少交、未来多交；DTA：现在多交、未来少交
│  │  └─ valuation allowance 增加会降低 DTA、增加 tax expense
│  ├─ 9.3 有效/法定/现金税率 (Effective / Statutory / Cash Tax Rates)
│  │  └─ ETR vs statutory 解释永久差异；cash tax rate 解释现金税负
├─ 10. Financial Reporting Quality
│  ├─ 10.1 报告质量 vs 报告结果质量 (Reporting Quality vs Quality of Reported Results)
│  │  └─ compliance 与 sustainability 是两个维度：高合规不保证高盈利质量
│  ├─ 10.2 稳健 vs 激进会计政策 (Conservative vs Aggressive Accounting)
│  │  └─ aggressive：提前收入/延后费用；conservative：延后收入/提前费用
│  ├─ 10.3 动机、机会与约束机制 (Motivation, Opportunity, Discipline Mechanisms)
│  │  └─ compensation、covenants、financing needs 与 weak controls 是常见风险组合
│  ├─ 10.4 Non-GAAP 与会计估计：检查调整是否反复出现、是否有经济实质
│  └─ 10.5 Warning signs：CFO < NI、AR 增速异常、审计师变更、频繁 fourth-quarter adjustments
├─ 11. Financial Analysis Techniques
│  ├─ 11.1 分析工具与局限 (Tools and Limitations)
│  │  └─ common-size / trend / cross-sectional / ratio；先统一口径再比较
│  ├─ 11.2 营运/流动性/偿债/盈利比率 (Activity / Liquidity / Solvency / Profitability Ratios)
│  │  └─ 周转率用平均余额；days ratios = 365 / turnover
│  ├─ 11.3 比率联动与行业比率 (Ratio Relationships and Industry-Specific Ratios)
│  │  └─ 单一比率不能直接下结论，必须与行业、趋势、相关比率交叉验证
│  ├─ 11.4 DuPont：ROE = net margin x asset turnover x financial leverage
├─ 12. Introduction to Financial Statement Modeling
│  ├─ 12.1 基于销售的 Pro Forma 模型 (Sales-Based Pro Forma Model)
│  │  └─ sales forecast 驱动 COGS/SG&A/WC；固定项目和融资缺口单独处理
│  ├─ 12.2 分析师预测偏差与修正 (Analyst Forecast Bias and Remedies)
│  │  └─ optimism/herding/selection bias 用 scenario、base-rate、cross-check 修正
│  ├─ 12.3 波特效应：价格与成本影响 (Porter Effects on Prices and Costs)
│  │  └─ 五力转成 price growth、COGS margin、reinvestment 和 terminal assumption
│  ├─ 12.4 Inflation/deflation：区分 volume growth 与 price growth
│  └─ 12.5 Forecast horizon：到竞争优势稳定为止；terminal growth 不应长期超过经济增速
```

## 4. 跨模块依赖关系

### 4.1 三表主干关系图

```text
Transactions
├─ accrual recognition -> Income Statement
│  ├─ NI -> retained earnings -> Balance Sheet
│  └─ NI -> starting point for indirect CFO -> Cash Flow Statement
├─ asset/liability/equity balances -> Balance Sheet
│  ├─ working capital changes -> CFO adjustments
│  ├─ PP&E/intangibles changes -> CFI and depreciation/amortization
│  └─ debt/equity changes -> CFF, leverage, interest coverage
└─ cash receipts/payments -> Cash Flow Statement
   ├─ CFO quality check against NI
   ├─ CFI explains reinvestment and asset base changes
   └─ CFF explains debt/equity financing and payout policy
```

### 4.2 依赖表：从报表项目到分析接口

| 起点 | 依赖对象 | 传导机制 | 输出到 | 考试判断 |
|---|---|---|---|---|
| M02 Income Statement | M04 Cash Flow | NI 加回 noncash items 并调整 working capital | CFO、earnings quality | NI 高但 CFO 弱，优先怀疑 accrual quality 或营运资本占用 |
| M02 Income Statement | M11 Ratios | revenue、COGS、operating income、NI 进入 margin 和 ROE | profitability、DuPont | 同一利润率变化要拆成 price、cost、volume、accounting choice |
| M03 Balance Sheet | M04 Cash Flow | AR、inventory、AP 的期初期末差额转为 CFO 调整 | direct/indirect CFO | 流动资产增加通常是 cash outflow；流动负债增加通常是 cash inflow |
| M03 Balance Sheet | M11 Ratios | current assets/liabilities、debt、equity、assets 作分母或分子 | liquidity、solvency、activity | 用平均余额计算周转率；用期末余额看结构 |
| M06 Inventories | M02/M11 | FIFO/LIFO/weighted average 改变 COGS、gross profit、inventory | gross margin、inventory turnover | 通胀下 FIFO 利润高、LIFO 税低且 CFO 高 |
| M06 Inventories | M09 Taxes | COGS 差异改变 taxable income 与 taxes payable | cash tax、DTA/DTL 判断 | LIFO reserve 调整后再跨公司比较 |
| M07 Long-Lived Assets | M02/M04 | depreciation/amortization/impairment 影响 NI，非现金费用加回 CFO | ROA、CFO bridge、asset turnover | 资本化只是改变费用时点；折旧不直接耗现金 |
| M08 Debt/Lease/Pension/Equity | M03/M11 | lease liability、PBO、debt/equity classification 改变负债和权益 | leverage、coverage、ROE | 表外或分类差异会扭曲 solvency，先读附注 |
| M09 Taxes | M02/M03/M04 | tax expense、taxes payable、DTA/DTL 分别进 IS/BS/SCF | ETR、cash tax rate、quality | permanent difference 不产生递延税；temporary difference 才转回 |
| M10 Quality | 全部模块 | 对收入、费用、估计、分类、non-GAAP 进行反向验证 | validation checklist | 质量判断必须有三表证据，不用单一利润指标定性 |
| M11 Techniques | M02-M10 | common-size、trend、ratio、DuPont 统一口径 | Equity/Credit/Corporate decisions | 比率解释必须同时写方向、原因、限制 |
| M12 Modeling | M02-M11 | sales-based forecast + ratio assumptions + cash flow valuation inputs | Equity valuation、credit forecast | 预测假设必须与历史比率、质量风险和行业结构一致 |

### 4.3 跨科目接口

| 接口 | FSA 输出 | 下游使用 | 检查点 |
|---|---|---|---|
| Equity | normalized earnings、FCFF/FCFE、ROE drivers、quality adjustments | DCF、relative valuation、growth assumptions | 不把一次性利润、LIFO liquidation、non-GAAP 调整直接资本化 |
| Credit / Fixed Income | CFO coverage、interest coverage、leverage、lease/pension obligations | default risk、covenant analysis、debt capacity | 租赁和养老金义务要纳入真实偿债压力 |
| Corporate Issuers | cash conversion cycle、working capital needs、capital structure | working capital policy、financing decisions | CCC 变差可能吞噬利润增长带来的现金 |
| Portfolio / Risk | reporting quality red flags、industry comparability | security selection、risk controls | 会计质量风险会转化为 forecast error 和 valuation risk |

## 5. 核心对比专题

| 重要性 | 对比项 | 英文 | 中文解释 | 考试判断 |
|---|---|---|---|---|
| ⭐⭐⭐ | 概念 vs 应用 | definition vs application | 先确认官方定义，再放入题干情境判断。 | 概念题也要能说出适用条件和例外。 |
| ⭐⭐⭐ | 计算 vs 解释 | calculation vs interpretation | 数值只是中间结果，答案要解释方向、含义和限制。 | 凡是 calculate and interpret 都不能只算。 |
| ⭐⭐ | 静态知识 vs 决策流程 | static knowledge vs decision process | 把每个模块压缩成输入 -> 工具 -> 输出 -> 陷阱。 | 流程化比孤立背诵更抗干扰。 |
| ⭐⭐⭐ | 英文识题 vs 中文理解 | English trigger vs Chinese explanation | 英文用于识别题干，中文用于确认真正含义。 | 避免看到熟词就按直觉作答。 |
| ⭐⭐ | 本模块 vs 跨模块 | single module vs cross-module use | 同一公式/概念可能在估值、风险、伦理或报表中换场景出现。 | 错题要回填到 MOC 节点。 |

## 6. 公式与框架速查

### Income Statement and Cash Flow

| 指标 | 公式 | 知识树节点 | 考试说明 |
|------|------|------------|----------|
| Gross Profit | `Revenue - COGS` | `2.5` | 【考纲重点】利润率与存货方法联动 |
| Operating Income | `Gross Profit - Operating Expenses` | `2.5` | 分析经营盈利能力 |
| Pretax Income | `EBT = EBIT - Interest Expense` | `2.5` | 税前利润口径 |
| Basic EPS | `(NI - Preferred Dividends) / Weighted Average Shares` | `2.4` | EPS 基础式 |
| Diluted EPS | `Adjusted NI Available to Common / Adjusted Weighted Average Shares` | `2.4` | 先排除 antidilutive instruments |
| CFO (Indirect) | `NI + Noncash Charges - Noncash Gains/Losses ± WC Changes` | `4.2` | 现金流重构核心 |
| Cash Collected from Customers | `Revenue - ΔAccounts Receivable` | `4.2` | 【考纲重点】直接法 CFO 常见转换 |
| Cash Paid to Suppliers | `COGS + ΔInventory - ΔAccounts Payable` | `4.2` | 直接法 CFO 常见转换 |
| Cash Paid for Operating Expenses | `Operating Expense - Depreciation + ΔPrepaids - ΔAccrued Expenses` | `4.2` | 题目会给简化项目 |
| FCFF | `FCFF = CFO + Interest(1 - T) - FCInv` | `5.2` | 公司自由现金流 |
| FCFE | `CFO - FCInv + Net Borrowing` | `5.2` | 股权自由现金流 |
| Common-Size IS Item | `Income Statement Item / Revenue` | `2.5` | 横向比较利润结构 |
| Cash Flow Common-Size Item | `Cash Flow Item / Revenue` 或 `/ Total Cash Inflows` | `5.1` | 题干会指定基数 |

### Liquidity and Activity

| 指标 | 公式 | 知识树节点 | 考试说明 |
|------|------|------------|----------|
| Current Ratio | `Current Assets / Current Liabilities` | `11.2` | 流动性 |
| Quick Ratio | `(Cash + ST Inv + Receivables) / CL` | `11.2` | 更保守流动性 |
| Inventory Turnover | `COGS / Average Inventory` | `11.2` | 存货效率 |
| Days Inventory | `365 / Inventory Turnover` | `11.2` | DIO 常与 CCC 联动 |
| Receivables Turnover | `Revenue / Average Receivables` | `11.2` | 回款效率 |
| DSO | `365 / Receivables Turnover` | `11.2` | 应收账款天数 |
| Payables Turnover | `Purchases / Average Trade Payables` | `11.2` | DPO 前置 |
| DPO | `365 / Payables Turnover` | `11.2` | 供应商付款天数 |
| Cash Conversion Cycle | `DIO + DSO - DPO` | `11.3` | FRA 与 Corporate Issuers 联动 |
| Total Asset Turnover | `Revenue / Average Total Assets` | `11.2` | 资产效率 |
| Working Capital | `Current Assets - Current Liabilities` | `3.4` | 短期资金占用 |
| Common-Size BS Item | `Balance Sheet Item / Total Assets` | `3.4` | 资产/资本结构分析 |
| LIFO Reserve Adjustment | `FIFO Inventory = LIFO Inventory + LIFO Reserve` | `6.2` | 【考纲重点】US GAAP LIFO 可比性调整 |
| FIFO COGS from LIFO | `FIFO COGS = LIFO COGS - ΔLIFO Reserve` | `6.2` | 通胀环境下常考方向 |
| FIFO Retained Earnings from LIFO | `LIFO RE + LIFO Reserve x (1 - Tax Rate)` | `6.2` | 可比性调整时常与 equity 联动 |
| Inventory Write-down | `Loss = Carrying Value - NRV` | `6.1` | NRV 低于成本时确认 |

### Profitability and Solvency

| 指标 | 公式 | 知识树节点 | 考试说明 |
|------|------|------------|----------|
| Gross Margin | `Gross Profit / Revenue` | `11.2` | revenue/COGS choice 的敏感点 |
| Operating Margin | `Operating Income / Revenue` | `11.2` | 经营盈利能力 |
| Pretax Margin | `Pretax Income / Revenue` | `11.2` | 税前盈利能力 |
| Net Margin | `NI / Revenue` | `11.4` | DuPont 第一段 |
| ROA | `NI / Average Total Assets` | `11.2` | 资产盈利能力 |
| ROE | `NI / Average Equity` | `11.4` | 股东回报 |
| Return on Invested Capital | `NOPAT / Average Invested Capital` | `11.2` | 【考纲重点】经营资本回报口径 |
| Financial Leverage | `Average Assets / Average Equity` | `11.4` | DuPont 杠杆段 |
| Debt-to-Equity | `Total Debt / Total Equity` | `11.2` | 偿债结构 |
| Debt-to-Assets | `Total Debt / Total Assets` | `11.2` | 偿债结构 |
| Debt-to-Capital | `Total Debt / (Total Debt + Total Equity)` | `11.2` | capital structure |
| Interest Coverage | `EBIT / Interest Expense` | `11.2` | 信用分析常用 |
| Fixed Charge Coverage | `(EBIT + Lease Payments) / (Interest + Lease Payments)` | `11.2` | 租赁压力纳入覆盖分析 |
| DuPont | `Net Margin x Asset Turnover x Financial Leverage` | `11.4` | ROE 分解 |
| Five-Step DuPont | `(NI/EBT) x (EBT/EBIT) x (EBIT/Revenue) x (Revenue/Assets) x (Assets/Equity)` | `11.4` | 【考纲重点】税负、利息、经营、效率、杠杆拆分 |

### Assets, Liabilities, Tax and Cash Quality

| 指标 | 公式 | 知识树节点 | 考试说明 |
|------|------|------------|----------|
| SL Depreciation | `(Cost - Residual Value) / Useful Life` | `7.2` | 折旧估计影响利润和资产 |
| DDB Depreciation | `(2 / Useful Life) x Beginning Net Book Value` | `7.2` | 前期折旧更高 |
| Carrying Amount | `Historical Cost - Accumulated Depreciation/Amortization - Impairment` | `7.2` | 减值与处置基础 |
| Gain/Loss on Disposal | `Sale Proceeds - Carrying Amount` | `7.2` | 处置损益进利润表 |
| Lease Liability | `PV of Lease Payments` | `8.1` | 租赁初始负债 |
| ROU Asset | `Lease Liability + Initial Direct Costs + Prepayments - Incentives` | `8.1` | 承租人资产确认 |
| Pension Funded Status | `Fair Value of Plan Assets - PBO` | `8.2` | 正值资产、负值负债 |
| Effective Tax Rate | `Income Tax Expense / Pretax Income` | `9.3` | 与 statutory rate 对比 |
| Cash Tax Rate | `Cash Taxes Paid / Pretax Income` | `9.3` | cash vs accrual tax lens |
| Deferred Tax Liability | `DTL = Taxable Temporary Difference x Tax Rate` | `9.2` | 【考纲重点】资产账面价值 > 税基通常产生 DTL |
| Deferred Tax Asset | `DTA = Deductible Temporary Difference x Tax Rate` | `9.2` | 可抵扣暂时性差异 |
| Income Tax Expense | `Taxes Payable + ΔDTL - ΔDTA` | `9.1` | 简化桥接，题干口径优先 |
| Operating Cash Flow Ratio | `CFO / Current Liabilities` | `5.3` | 覆盖短期负债 |
| Free Cash Flow to Firm Coverage | `FCFF / Total Debt` | `5.3` | cash-flow coverage 直觉 |
| Accruals Ratio | `(NI - CFO) / Average Total Assets` | `10.5` | 【考纲重点】盈利质量预警，口径以题目为准 |
| Quality of Earnings | `CFO / Net Income` | `10.5` | >1 通常说明现金支撑较强，但要排除一次性营运资本影响 |

## 8. 通用分析框架

### 框架1：会计政策影响决策树

```text
题干给出 accounting choice / estimate / classification
├─ Step 1: 识别对象
│  ├─ revenue timing -> M02.1
│  ├─ expense vs capitalize -> M02.2 / M07.2
│  ├─ FIFO/LIFO/weighted average -> M06.2
│  ├─ lease / pension / stock compensation -> M08
│  └─ tax timing -> M09
├─ Step 2: 先问是否改变现金
│  ├─ 不改变现金：depreciation、amortization、impairment、stock comp、DTA/DTL creation
│  └─ 改变现金：taxes paid、capex、lease payments、debt issuance/repayment
├─ Step 3: 三表方向
│  ├─ IS：Revenue - COGS - operating expenses - interest - tax = NI
│  ├─ BS：Assets = Liabilities + Equity，注意 retained earnings 和 deferred taxes
│  └─ SCF：CFO 从 NI 调整；CFI 看 asset purchase/sale；CFF 看 debt/equity/lease financing
└─ Step 4: 比率影响
   ├─ profitability：margin、ROA、ROE
   ├─ activity：turnover 用 average balance
   ├─ liquidity：current / quick / CFO ratio
   └─ solvency：debt ratios、coverage、financial leverage
```

### 框架2：公式选择条件

| 题干触发 | 先选公式/框架 | 使用条件 | 解释输出 |
|---|---|---|---|
| “basic EPS” | `(NI - Preferred Dividends) / WASO` | 简单资本结构或只问基础 EPS | EPS 是普通股股东收益口径，不用期末股数 |
| “diluted EPS / convertible / options” | adjusted NI / adjusted shares | 先测试 antidilutive；反稀释排除 | 稀释 EPS 通常低于或等于 basic EPS |
| “cash collected from customers” | `Revenue - ΔAR` | 无坏账/预收等复杂信息时 | 应收增加表示部分收入未收现 |
| “cash paid to suppliers” | `COGS + ΔInventory - ΔAP` | 存货与应付为主要调整项 | 存货增加和应付减少都消耗现金 |
| “FCFF” | `CFO + Interest(1 - T) - FCInv` | 从 CFO 出发且给所有资本提供者 | 加回税后利息，扣资本投资 |
| “FCFE” | `CFO - FCInv + Net Borrowing` | 股东可得现金流 | 借款增加提高 FCFE，偿债降低 FCFE |
| “inventory method comparison” | LIFO reserve 调整 | US GAAP LIFO 公司与 FIFO 公司比较 | 通胀/通缩先判断，再解释 COGS、NI、tax、CFO |
| “temporary difference” | DTA/DTL = difference x tax rate | 会在未来转回 | 现在少交未来多交是 DTL；现在多交未来少交是 DTA |
| “quality of earnings” | `CFO / NI`、`(NI - CFO) / Average Assets` | NI 与 CFO 可得 | CFO 长期弱于 NI 是 accrual/red flag |
| “ROE driver” | DuPont 三步或五步 | 题干要求分解变化来源 | 区分 margin、efficiency、leverage、tax、interest drivers |
| “sales-based model” | percentage-of-sales | 项目随销售稳定变动 | 固定资产、债务、利息和 plug 要单独判断 |

### 框架3：现金流质量判断树

1. 从 `Net Income` 出发，拆出 noncash charges/gains。
2. 检查 `AR / Inventory / AP`：收入增长若伴随 AR 和 inventory 过快增长，CFO 质量下降。
3. 计算或解释 `CFO`，再区分：
   - CFO 强、NI 弱：可能有保守会计或一次性费用。
   - NI 强、CFO 弱：可能有激进收入确认、库存堆积或回款恶化。
4. 若题干进入估值或股东现金流，再选：
   - 全公司口径：`FCFF = CFO + Interest(1 - T) - FCInv`
   - 股东口径：`FCFE = CFO - FCInv + Net Borrowing`
5. 回到可持续性：经营现金是否来自核心业务，还是来自 working capital release 或一次性处置。

### 框架4：比率解释决策树

1. 先归类：liquidity / activity / solvency / profitability / cash flow / valuation input。
2. 再确定分子分母是否受同一会计政策影响：
   - FIFO/LIFO 同时影响 COGS、inventory、tax、NI。
   - Capitalize/expense 同时影响 assets、expenses、NI、CFO/CFI 分类。
   - Lease recognition 同时影响 assets、liabilities、EBITDA、interest。
3. 选择比较口径：
   - 规模比较用 common-size。
   - 趋势判断用 multi-period trend。
   - 同业比较先调整 accounting policy 和 fiscal year。
4. 输出必须包含：数值方向、业务含义、会计限制、下一步验证证据。

- **考前压缩**。只保留高频术语、公式/框架、易错点、跨模块依赖和错题触发点。
