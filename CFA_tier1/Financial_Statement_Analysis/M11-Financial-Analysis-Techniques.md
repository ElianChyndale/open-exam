# M11: Financial Analysis Techniques

> **模块定位 Module role**: turn financial statements into comparable ratios, trends, peer analysis, DuPont drivers, and forecasting inputs.

## 0. Reading Contract 阅读契约

**Official module**: Module 11: Financial Analysis Techniques
**Exam task**: describe analysis tools and limits, calculate/interpret activity/liquidity/solvency/profitability ratios, evaluate companies using ratio relationships, apply DuPont, identify industry ratios, and use ratios for modeling/forecasting.

Learning outcome actions:

- Describe financial analysis tools, uses, and limitations.
- Calculate and interpret activity, liquidity, solvency, and profitability ratios.
- Evaluate a company using relationships among ratios.
- Apply DuPont analysis of ROE.
- Describe industry-specific ratios.
- Describe how ratios and other techniques support modeling and forecasting.

## 1. Module Brief 模块定位

M11 is the calculation hub of FSA. A correct answer needs three layers: formula, comparison base, and business interpretation. Ratios are not standalone facts; they need trend, peer, industry, accounting policy, and strategy context.

Core English anchors: common-size analysis, trend analysis, cross-sectional analysis, regression, activity ratios, liquidity ratios, solvency ratios, profitability ratios, DuPont analysis, industry-specific ratios, model building, forecasting.

## 2. Curriculum Spine 教材主线

1. **Analysis process**: objectives, computations versus analysis.
2. **Tools**: ratios, common-size, trend, cross-sectional, graphs, regression.
3. **Ratio universe and limits**: usefulness depends on definitions, accounting policy, seasonality, and industry.
4. **Ratio categories**: activity, liquidity, solvency, profitability.
5. **Integrated analysis**: connect ratios instead of treating them separately.
6. **DuPont**: decompose ROE into margin, turnover, and leverage.
7. **Industry ratios and forecasting**: use relevant drivers for model building.

## 3. Exam Translation 考试翻译

| Prompt Signal | Translate To | Answer Move |
|---|---|---|
| "efficiency" | activity ratio | Inventory turnover, receivables turnover, asset turnover |
| "short-term liquidity" | liquidity ratio | Current, quick, cash, defensive interval, cash conversion cycle |
| "long-term risk" | solvency ratio | Debt ratios, leverage, coverage |
| "profitability" | margin/return ratio | Gross/operating/net margin, ROA, ROE, ROIC |
| "why ROE changed" | DuPont | Margin vs asset turnover vs leverage |
| "forecast" | driver model | Use sales growth, margins, turnover, capex, working capital |

## 4. Formula & Decision Bench 公式与判断台

| Formula / Framework | Use |
|---|---|
| Inventory turnover = COGS / average inventory; DOH = 365 / inventory turnover | Inventory efficiency |
| Receivables turnover = revenue / average receivables; DSO = 365 / turnover | Collection speed |
| Payables turnover = purchases / average payables; DPO = 365 / turnover | Supplier payment speed |
| Cash conversion cycle = DOH + DSO - DPO | Working capital cycle |
| Current ratio = current assets / current liabilities | Liquidity |
| Quick ratio = (cash + marketable securities + receivables) / current liabilities | More conservative liquidity |
| Debt-to-assets = total debt / total assets | Solvency |
| Debt-to-equity = total debt / total equity | Capital structure risk |
| Interest coverage = EBIT / interest expense | Ability to service interest |
| Gross/operating/net margin = profit measure / revenue | Profitability by layer |
| ROA = net income / average total assets | Asset profitability |
| ROE = net income / average equity | Equity profitability |
| DuPont ROE = net margin x asset turnover x financial leverage | ROE driver attribution |

Decision bench:

```text
Calculate -> Compare trend/peer/industry -> Identify driver -> Check accounting policy -> State business meaning
```

## 6. Trap Ledger 易错账本

| Trap | Fix Rule |
|---|---|
| Higher ratio always better | Interpret by category; high leverage or DPO can signal risk |
| Turnover and days direction confused | Higher turnover means fewer days, all else equal |
| ROE improvement praised automatically | DuPont may reveal leverage-driven ROE |
| Ratio compared across different accounting policies | Adjust or flag comparability limitation |
| Formula answer without interpretation | Always state driver and business implication |

## 7. Final Recall Sheet 终局速记

- Activity: turnover and days. Liquidity: current/quick/cash/CCC. Solvency: debt/leverage/coverage. Profitability: margins/returns.
- CCC = DOH + DSO - DPO.
- DuPont: ROE = net margin x asset turnover x financial leverage.
- Ratios require context: trend, peer, industry, accounting policy, and strategy.
- Forecasting uses ratio drivers, not historical averages blindly.
