# M01: Introduction to Financial Statement Analysis

> **模块定位 Module role**: build the analyst's evidence workflow before any calculation: purpose -> data -> processing -> analysis -> communication -> follow-up.

## 0. Reading Contract 阅读契约

**Official module**: Module 1: Introduction to Financial Statement Analysis
**Exam task**: describe the FSA framework, analyst roles, regulated information sources, implications of alternative reporting systems, and non-report sources.

Learning outcome actions:

- Describe the six-step financial statement analysis framework.
- Explain what analysts use financial statements for: equity, credit, performance, risk, stewardship, and forecasting.
- Evaluate the importance of regulatory filings, notes, supplementary schedules, management commentary / MD&A, and audit reports.
- Explain why IFRS, US GAAP, and evolving standards affect comparability.
- Identify other information sources beyond annual and interim financial reports.

## 1. Module Brief 模块定位

本模块不考复杂公式，考的是 **where evidence comes from and how an analyst should use it**。FSA 的默认动作不是“看见报表数字就算”，而是先确认目的、信息质量、披露口径和可比性。

Core English anchors: financial statement analysis framework, purpose and context, regulatory filings, notes, supplementary schedules, segment reporting, MD&A, audit report, alternative reporting systems, information sources.

## 2. Curriculum Spine 教材主线

1. **Framework**: articulate purpose and context -> collect data -> process data -> analyze/interpret data -> develop and communicate conclusions -> follow up.
2. **Scope**: FSA supports security valuation, credit analysis, management performance review, compliance, and forecast formation.
3. **Regulated sources**: annual/interim reports, securities filings, notes, supplementary schedules, segment data, MD&A, and audit reports.
4. **Reporting systems**: IFRS, US GAAP, local GAAP, and standard changes create comparability issues.
5. **Other sources**: press releases, conference calls, industry data, economic data, company websites, and third-party research.

## 3. Exam Translation 考试翻译

| Prompt Signal | Translate To | Answer Move |
|---|---|---|
| "first step", "purpose", "client need" | framework setup | Purpose and context come before collecting data |
| "notes", "supplementary schedules" | disclosure evidence | Use them to understand policies, estimates, segments, commitments |
| "MD&A" | management perspective | Helpful but subjective; compare with audited statements |
| "audit report" | assurance signal | Clean opinion is not a guarantee of business quality |
| "different GAAP" | comparability issue | Adjust or disclose limits before peer comparison |

## 4. Formula & Decision Bench 公式与判断台

No core numerical formula. Decision framework:

```text
Purpose -> Required data -> Data reliability -> Accounting comparability -> Analysis method -> Recommendation -> Follow-up
```

Use this module as the checklist before all later calculations: if a ratio answer ignores source quality or accounting comparability, the interpretation is incomplete.

## 6. Trap Ledger 易错账本

| Trap | Fix Rule |
|---|---|
| 把 "collect data" 放在第一步 | Always start with purpose and context |
| 把 audit report 当成盈利质量保证 | Audit opinion addresses financial statement presentation, not investment attractiveness |
| 只看 primary statements | Notes, schedules, MD&A, and filings often contain the tested detail |
| 忽略 reporting system differences | Before peer ratios, ask whether accounting policies and standards are comparable |

## 7. Final Recall Sheet 终局速记

- Six steps: purpose/context, collect data, process data, analyze, communicate, follow up.
- Sources: financial statements, notes, supplementary schedules, MD&A, audit report, regulatory filings, external data.
- MD&A is useful but management-authored; audit report gives assurance but not valuation judgment.
- Comparability is an analytical task, not an assumption.
