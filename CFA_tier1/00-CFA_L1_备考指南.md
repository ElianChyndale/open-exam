## 财务分析 Financial Statement Analysis

**我的方法：默写 + 情景化**

### 1. 默写三张表的基本结构

- 资产负债表 B/S
- 利润表 I/S
- 现金流量表 C/F

### 2. 放在情景中理解联动

- 一项交易发生，三张表分别怎么变？
- 折旧方法切换，对 NI、CF、Ratio 的连锁影响？

> **财务不是背的，是推演出来的。**

## 公司金融 Corporate Issuers

**核心要点：MM理论一定要理解**

- 无税 MM / 有税 MM / 权衡理论 / 优序融资理论
- 不是背结论，而是**理解为什么杠杆会影响价值**

### 其他模块

- **ESG、公司治理** → 偏记忆，考前过一遍
- **资本预算（NPV/IRR）** → 和财务分析联动，一起理解

## 其他科目一句话

| 科目 | 核心体感 |
|------|----------|
| **股权 Equity** | 估值模型、指数加权方法、市场有效性、行为金融 |
| **固收 Fixed Income** | duration / convexity 计算套路固定，注意含权债券的区别 |
| **衍生品 Derivatives** | 估值（无套利原理）、期权平价公式 |
| **另类 Alternative** | 私募股权、房地产、大宗商品，内容少，但概念杂，需要重点记忆 |
| **投资组合 Portfolio** | 投资组合理论、IPS、行为金融，框架感强，建议搭框架记忆 |
| **道德 Ethics** | 题量大，很重要：菜，就要多练 |
| **考试过程** | 速度放慢、看清单词、写出公式来对比 |

## 04 如何用 Kimi Code 备考

**它帮我解决了两大痛点：**

| 痛点 | 传统方式 | Kimi Code 方式 |
|------|----------|----------------|
| **知识点理解** | 翻书、查百度、问群 | 直接问，让它举例子辅助理解 |
| **错题本整理** | 手动抄写、格式混乱 | 本地 Agent 自动归档、统一模板 |

## 用法一：举例子，秒懂抽象概念

**场景：** 假设检验的 Type I / Type II error 总混？

**操作：**

> "给我举一个 CFA 考试场景下的例子，说明 Type I 和 Type II error 的区别"

**结果：** 它会给一个投资研究的具体场景，比课本定义好记10倍。

> **任何抽象概念，都可以用这个句式：**
> "给我举个例子，让我在 CFA 考试场景下理解 XXX"

## 理解 + 记忆 = 两层楼

```
┌─────────────────────────┐
│        记忆层            │  ← 知识地图（MOC）用于记忆
│      回忆 / 检索         │
├─────────────────────────┤
│        理解层            │  ← 知识点 + 错题 用于理解
│      推导 / 应用         │
└─────────────────────────┘
```

- **知识点**：搭起学科框架
- **错题**：在框架上打补丁，标记你理解薄弱的地方
- **知识地图**：把框架和补丁变成一张**可检索的索引**

---

## 知识地图是什么？

**与「记忆挂钩的目录」**

- 看到题目关键词 → **3秒内定位到模块** → 调用对应知识组块
- 例："NPV vs IRR 冲突" → 立刻想到 **M05 资本投资** → 再投资假设、规模问题

### 制作原则

1. 按模块组织树状结构
2. 跨模块关联用箭头标注
3. 嵌入错题双向链接
4. 包含 Checklist 式解题框架

> 我的知识地图就存在 `skills/cfa-moc-methodology/` 里，随用随查。

## CFA 一级备考总结

1. **时间不够，别刷课后题** —— 直接知识点 + Practice Pack 1000 + Mock
2. **不懂就问，让 AI 举例子** —— 抽象概念瞬间落地
3. **知识点搭框架，错题打补丁，最终汇成知识地图** —— 记忆为了理解，理解也为了记忆
