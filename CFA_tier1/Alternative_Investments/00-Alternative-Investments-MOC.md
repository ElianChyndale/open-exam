## 核心知识树

```text
📊 Alternative Investments (7-10%) (M01-M07) 知识体系

├─ 🏆 M01: Alternative Investment Features, Methods, and Structures（另类投资基础）
│  ├─ ⭐ 另类投资特征：低流动性·非正态回报·高费用·经理alpha
│  ├─ ⭐ 投资方式：直接投资(全控)·共同投资(分摊)·基金(专业管理)
│  └─ ⭐ GP/LP结构：GP管理+出资少量·LP出大部分资金·capital call
│
├─ 🏆 M02: Performance and Returns（费用与回报）【高频计算】
│  ├─ 📐 Management Fee = 承诺资本/NAV × 费率（通常2%）
│  ├─ 📐 Performance Fee = max(0,超额收益) × 费率（通常20%）
│  ├─ 🎯 High-water Mark：超过历史最高NAV才计提业绩报酬
│  ├─ 📐 Net Return = Total Return - Mgmt Fee - Performance Fee
│  └─ ⚠️ 费用结构复杂——高费用不保证高净回报
│
├─ 🏆 M03: Private Capital（私募资本）
│  ├─ ⭐ PE策略：LBO(杠杆收购)·VC成长·VC初创·困境投资
│  ├─ ⭐ Private Debt：直接贷款·CLO等
│  └─ 🎯 Diversification benefits：与传统资产相关性低
│
├─ 🏆 M04: Real Estate and Infrastructure（房地产与基础设施）
│  ├─ ⭐ 房地产：直接拥有·REIT·房地产基金
│  ├─ ⭐ 基础设施：交通·能源·公用事业——长期稳定现金流
│  └─ 🎯 通胀对冲·低相关性·长期锁定期
│
├─ 🏆 M05: Natural Resources（自然资源）
│  ├─ ⭐ 大宗商品：现货·期货·ETF
│  ├─ ⭐ 农田/林地：通胀敏感·生物转化价值
│  └─ ⚠️ 风险：天气·政策·价格周期
│
├─ 🏆 M06: Hedge Funds（对冲基金）
│  ├─ ⭐ HF策略
│  │  ├─ Long/Short：买入看好，卖空看差
│  │  ├─ Event-Driven：并购套利·困境证券
│  │  ├─ Relative Value：统计套利·可转债套利
│  │  └─ Global Macro：基于宏观判断的多资产
│  ├─ 📐 费用：2/20 + hurdle + HWM
│  └─ ⚠️ 风险：杠杆风险·流动性错配·经理离职
│
└─ 🏆 M07: Digital Assets（数字资产）── 2026新模块
   ├─ ⭐ DLT（分布式账本）、区块链、共识机制
   ├─ ⭐ 加密货币（BTC/ETH）vs 代币化(Tokenization)
   └─ ⚠️ 波动性·监管不确定性·托管风险
```

## 🔑 核心对比专题

| 对比 | 🔑 区别 | 🎯 判断 |
|------|---------|---------|
| **PE vs HF** | PE长期锁定·capital call；HF可定期赎回 | 锁定期→PE |
| **直接 vs 基金投资** | 全控 vs 专业管理分散风险 | |
| **RE vs Infrastructure** | RE靠增值+租金；Infra长期稳定现金流 | |
| **Hurdle vs HWM** | hurdle年度最低；HWM历史累计峰值 | 两个条件都要满足 |
| **VC vs LBO** | VC早期成长；LBO成熟现金流 | |


```
Step 1 ─── 确定管理费率(通常2% of NAV)

```

## 通用分析框架

### 另类投资选择框架
1. 流动性需求：高 → avoid PE/RE；可5-10年锁定 → PE/RE
2. 回报目标：追求绝对回报 → HF；追求长期增长 → PE；通胀对冲 → RE/大宗
3. 风险承受：高风险可接受 → VC、数字资产；中等 → LBO、RE

### 费用分析四步
1. 确定管理费率（通常 2% of committed/NAV）
2. 确定业绩报酬率（通常 20%）
3. 检查 hurdle rate 和 high-water mark 条件
4. 计算净回报 = 总回报 - 管理费 - 业绩报酬
