## 🌳 核心知识树

```text
🏢 Corporate Issuers (6-9%) (M01-M07) 知识体系

├─ 🏆 M01: Organizational Forms, Features, and Ownership（组织形式与所有权）
│  ├─ ⭐ 1.1 企业法律形式
│  │  ├─ 独资(Sole P.)：无限责任·个人税·融资困难
│  │  ├─ 合伙(Partnership)：GP无限责任·LP有限责任·税务穿透
│  │  ├─ 公司(Corp)：有限责任·双重征税·融资灵活
│  │  └─ LLC：有限责任+税务穿透（混合结构）
│  ├─ ⭐ 1.2 债务vs股权索偿
│  │  ├─ 债权人：固定合约索偿权（优先受偿）
│  │  └─ 股东：剩余索偿权（更高风险·上行空间）
│  ├─ 🎯 所有权vs控制权分离→代理问题(principal-agent)
│  └─ ⚠️ 有限责任≠公司不会破产（股东个人资产才受保护）
│
├─ 🏆 M02: Investors and Other Stakeholders（利益相关者）
│  ├─ ⭐ 股东追求价值↑ vs 债权人追求稳定↓（目标冲突）
│  └─ ⭐ ESG因素：环境·社会·治理
│
├─ 🏆 M03: Corporate Governance（公司治理）
│  ├─ ⭐ 代理冲突：股东vs经理·大股东vs小股东·股东vs债权人
│  ├─ ⭐ 治理机制：董事会·薪酬·审计·合规
│  └─ 🎯 治理风险（弱治理→利益侵占）vs 治理收益（强治理→价值提升）
│
├─ 🏆 M04: Working Capital and Liquidity（营运资本）【计算】
│  ├─ 📐 CCC = DOH + DSO - DPO（现金转换周期）
│  │  ├─ DOH = 365/Inventory Turnover（存货天数）
│  │  ├─ DSO = 365/Receivables Turnover（应收天数）
│  │  └─ DPO = 365/Payables Turnover（应付天数）
│  └─ ⚠️ CCC越短≠越好！过短可能意味供货商受压迫或库存短缺
│
├─ 🏆 M05: Capital Investments and Capital Allocation（资本投资）【高频计算】
│  ├─ 📐 NPV = ΣCFt/(1+r)^t - I₀（净现值）
│  │  🎯 NPV>0→接受项目（创造价值）
│  ├─ 📐 IRR = NPV=0时的r（内部收益率）
│  │  🎯 IRR>资本成本→接受
│  ├─ 📐 ROIC = NOPAT / Invested Capital
│  │  🎯 ROIC>WACC→创造价值
│  └─ ⚠️ 互斥项目：NPV为准！IRR可能有排序问题（规模/时间差异）
│
├─ 🏆 M06: Capital Structure（资本结构）【高频计算】
│  ├─ 📐 WACC = wd·rd(1-t) + we·re
│  │  ⚠️ WACC是公司平均成本，项目风险不同需调整
│  ├─ ⭐ MM定理
│  │  ├─ MM无税：VU = VL（资本结构无关，无最优结构）
│  │  └─ MM有税：VL = VU + tD（负债有税盾→100%负债最优？）
│  ├─ 🎯 最优结构：税盾边际收益 = 财务困境边际成本
│  └─ ⚠️ 杠杆↑→权益成本↑（股东要求更高回报补偿财务风险）
│
└─ 🏆 M07: Business Models（商业模式）── 2026新模块
   └─ ⭐ 关键要素：价值主张·收入模式·成本结构·竞争壁垒
```

## 🔑 核心对比专题

| 对比项 | 🔑 关键区别 | 🎯 考试判断 |
|--------|-------------|-------------|
| 独资 vs 公司 | 无限+个人税 vs 有限+双重税 | 责任和税务 |
| 股东 vs 债权人 | 剩余索偿 vs 固定索偿 | 谁优先？→债权人 |
| NPV vs IRR | 金额 vs 回报率 | 互斥→NPV优先 |
| MM无税 vs 有税 | VU=VL vs VL=VU+tD | 负债→税盾 |
| 税盾 vs 困境成本 | 最优杠杆=两者平衡 | 权衡理论 |

## 📐 核心公式速查

| 公式 | 用途 | ⚠️ |
|------|------|-----|
| CCC = DOH+DSO-DPO | 现金转换周期 | |
| NPV = ΣCFt/(1+r)^t-I₀ | 净现值 | >0接受 |
| WACC = wd·rd(1-t)+we·re | 资本成本 | 税后负债 |
| VL = VU+tD（MM有税） | 杠杆公司价值 | |
| ROIC = NOPAT/IC | 投入资本回报率 | >WACC=价值创造 |

## 🚨 高频陷阱速查

| ❌ 错误 | ✅ 正确 | 🎯 |
|---------|---------|-----|
| 有限责任=公司不会倒 | 公司可破产，股东个人资产受保护 | ⭐⭐ |
| WACC对所有项目一样 | 项目风险不同需调整 | ⭐⭐⭐ |
| MM说负债没用 | 有税版本说负债有税盾好处 | ⭐⭐⭐ |
| IRR永远比NPV好 | 互斥项目以NPV为准 | ⭐⭐⭐ |
| CCC越短=越好 | 过短可能压供货商 | ⭐⭐ |
| NPV和IRR总是同向 | 互斥项目可能冲突 | ⭐⭐ |
