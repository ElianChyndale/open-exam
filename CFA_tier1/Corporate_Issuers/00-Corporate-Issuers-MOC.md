> **一句话核心**：理解公司组织、治理、营运资本、资本配置与商业模式如何影响价值创造。

## 3. 核心知识树

```text
Corporate Issuers (6-9%)
├─ 1. Organizational Forms, Corporate Issuer Features, and Ownership
│  ├─ 1.1 组织形式：sole proprietorship / partnership / corporation / LLC；判断 limited liability、tax、control、capital access。
│  ├─ 1.2 公司发行人特征：separate legal entity、limited liability、transferable ownership、perpetual life。
│  ├─ 1.3 所有权结构：private/public、concentrated/dispersed、dual-class；决定代理问题和治理机制。
│  └─ 1.4 考试判断：公司制提高融资能力，但引入 ownership-control separation。
├─ 2. Investors and Other Stakeholders
│  ├─ 2.1 投资者类型：shareholders、creditors、institutional/retail；区分 residual claim 与 contractual claim。
│  ├─ 2.2 利益相关者目标：shareholders 要 value，creditors 要 downside protection，employees/customers/regulators 各有约束。
│  ├─ 2.3 冲突类型：shareholder-manager、shareholder-creditor、controlling-minority、firm-other stakeholders。
│  └─ 2.4 信息不对称：adverse selection 是交易前，moral hazard 是交易后，signaling 要看行动是否可信。
├─ 3. Corporate Governance: Conflicts, Mechanisms, Risks, and Benefits
│  ├─ 3.1 代理问题：principal-agent 信息、控制权和激励不一致；治理目标是降低 agency costs。
│  ├─ 3.2 治理机制：board independence、committees、compensation、audit、shareholder rights、takeover market。
│  ├─ 3.3 治理风险：弱监督导致 tunneling、empire building、overinvestment、risk shifting、disclosure quality 下降。
│  └─ 3.4 ESG/Stewardship：只有 material ESG 会通过 cash flow、risk 或 cost of capital 影响价值。
├─ 4. Working Capital and Liquidity
│  ├─ 4.1 经营周期：`Operating cycle = DIO + DSO`；从采购/生产到销售回款的时间。
│  ├─ 4.2 现金转换周期：`CCC = DIO + DSO - DPO`；越短通常占用现金越少，但可能牺牲服务或信用质量。
│  ├─ 4.3 营运资本政策：aggressive 低缓冲高风险，conservative 高缓冲低收益；看 cash flow predictability。
│  └─ 4.4 流动性比率：current/quick/cash ratio 反映偿付能力，但过高可能是低效资本占用。
├─ 5. Capital Investments and Capital Allocation
│  ├─ 5.1 增量现金流：忽略 sunk cost，纳入 opportunity cost、externality、tax、salvage、working capital。
│  ├─ 5.2 决策标准：NPV 最大化价值；IRR/PI/payback 回答辅助问题，互斥项目冲突时回到 NPV。
│  ├─ 5.3 项目类型：independent、mutually exclusive、capital rationing；不同约束下排序规则不同。
│  └─ 5.4 实物期权：delay、expand、abandon、flexibility 会提高项目价值，但不能替代基础现金流分析。
├─ 6. Capital Structure
│  ├─ 6.1 资本成本：after-tax cost of debt、preferred cost、CAPM/DDM/BYPRP cost of equity、market-value WACC。
│  ├─ 6.2 杠杆机制：DOL 来自 fixed operating costs，DFL 来自 fixed financing costs，DTL 把 sales shock 传到 EPS。
│  ├─ 6.3 资本结构权衡：tax shield vs financial distress、agency cost、flexibility、signaling。
│  └─ 6.4 考试判断：公司 WACC 不是所有项目的通用 hurdle rate；项目风险不同时要调折现率。
├─ 7. Business Models
│  ├─ 7.1 商业模式定义：value proposition、target customer、revenue model、cost structure、resources/capabilities。
│  ├─ 7.2 模式类型：subscription、transaction、platform、asset-light、asset-heavy、financial intermediation 等。
│  ├─ 7.3 质量判断：unit economics、scalability、recurring revenue、switching costs、cash conversion、reinvestment need。
│  └─ 7.4 与资本配置连接：高增长若 unit economics 差或再投资回报低，仍可能毁灭价值。
```

### M04 Working Capital

| 指标 | 公式 | 知识树节点 | 考试说明 |
|------|------|------------|----------|
| Operating cycle | `DIO + DSO` | `4.1` | 销售与回款链。 |
| Cash conversion cycle | `DIO + DSO - DPO` | `4.2` | 【考纲重点】营运资本核心；DPO 延长会缩短 CCC 但可能伤害供应商关系。 |
| Working capital | `Current assets - current liabilities` | `4.4` | 流动性规模，不等于经营效率。 |
| Net operating working capital | `Operating current assets - operating current liabilities` | `4.2` | 项目现金流常用 operating 口径。 |
| DIO | `(Average inventory / COGS) x 365` | `4.1` | 题目给 turnover 时用 `365 / inventory turnover`。 |
| DSO | `(Average receivables / revenue) x 365` | `4.1` | collection speed；上升可能代表信用放松或回款恶化。 |
| DPO | `(Average payables / purchases or COGS) x 365` | `4.2` | denominator 读题；采购额不给时常用 COGS 近似。 |
| Current ratio | `Current assets / current liabilities` | `4.4` | 高不一定好，可能资产闲置。 |
| Quick ratio | `(Cash + marketable securities + receivables) / current liabilities` | `4.4` | 排除 inventory。 |
| Cash ratio | `(Cash + marketable securities) / current liabilities` | `4.4` | 最保守流动性指标。 |
| Inventory turnover | `COGS / average inventory` | `4.1` | 与 DIO 方向相反。 |
| Receivables turnover | `Revenue / average receivables` | `4.1` | 与 DSO 方向相反。 |
| Payables turnover | `Purchases or COGS / average payables` | `4.2` | 与 DPO 方向相反。 |

| 指标 | 公式 | 知识树节点 | 考试说明 |
|------|------|------------|----------|
| Net present value | `NPV = Σ CF_t/(1 + r)^t - initial outlay` | `5.2` | value rule 主指标；独立项目 NPV > 0 接受。 |
| Internal rate of return | `0 = Σ CF_t/(1 + IRR)^t - initial outlay` | `5.2` | 非常规现金流可能多 IRR 或无 IRR。 |

## 8. 通用分析框架

### 框架1：资本预算决策树

1. 先识别项目关系：independent 用 accept/reject，mutually exclusive 用排序，capital rationing 用有限资本组合。
2. 建现金流时间轴：initial outlay、annual OCF、terminal cash flow；只放 incremental after-tax cash flows。
3. 现金流筛选：排除 sunk cost；纳入 opportunity cost、cannibalization、externality、NOWC、salvage tax effect。
4. 折现率选择：项目风险等于公司平均风险才用 company WACC；风险不同则调整 hurdle rate。
5. 决策规则：NPV 为主；IRR 与 NPV 冲突时选 NPV；PI 用于 capital rationing；EAA 用于不同寿命互斥项目。

### 框架2：WACC/资本结构决策树

1. 识别资本来源：debt、preferred、common equity；用 target market-value weights。
2. 计算 component costs：debt 要 after-tax，preferred 用 `D_p/P_p`，equity 在 CAPM/DDM/BYPRP 中按题目信息选择。
3. 合成 `WACC = w_d r_d(1-T) + w_p r_p + w_e r_e`。
4. 检查用途：WACC 是 marginal cost of capital，不是历史 book cost；只适用于相同风险项目。
5. 判断资本结构：债务增加带来 tax shield，同时提高 distress cost、agency cost 和财务灵活性损失。

### 框架3：治理-营运资本-商业模式联动树

1. 治理题先找冲突主体：manager/shareholder、shareholder/creditor、controlling/minority、firm/stakeholder。
2. 再匹配机制：board、compensation、audit、disclosure、covenants、shareholder voting、engagement。
3. 营运资本题先拆 `DIO + DSO - DPO`，再判断缩短 CCC 是效率改善还是风险前移。
4. 商业模式题用四问：收入是否 recurring，unit economics 是否为正，扩张是否提高 operating leverage，增长是否需要大量再投资。
5. 最后落到价值：任何治理、流动性或模式变化，都要说明它通过 cash flow、risk、growth 或 cost of capital 影响价值。
