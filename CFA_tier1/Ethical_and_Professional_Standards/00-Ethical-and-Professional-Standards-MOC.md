## 最关键：先看客户利益，再看标准触发，再看最保守做法

Ethics 的核心不是背条文，而是稳定地做出“最可辩护”的职业判断。

## 核心对比专题

| 对比项 | 本质 | 风险 | 回报/用途 | 相关性 | 费用/代价 |
|--------|------|------|-----------|--------|-----------|
| Law vs CFA Standards | 法律底线 vs 职业标准 | 选错优先级会违规 | 用 stricter standard 保护职业判断 | 常与 employer policy 混淆 | 代价是可能放弃短期利益 |
| Mosaic Theory vs MNPI | 合法拼接公开/非重大信息 vs 使用重大非公开信息 | 误把 MNPI 包装成 mosaic | 合法研究框架 | 都涉及信息优势 | 违规代价极高 |
| Fair Dealing vs Suitability | 公平分配机会 vs 个性化匹配客户需求 | 把两者混为一谈 | 一个管过程公平，一个管推荐适配 | 都属于 duties to clients | 不合规会伤害客户与声誉 |
| Disclosure vs Elimination of Conflict | 披露冲突 vs 根除冲突 | 以为披露后任何冲突都可接受 | disclosure 是最低动作，不总是充分 | 常与 independence 混淆 | 可能牺牲业务便利 |
| GIPS Verification vs Performance Accuracy | 验证 firm-level process vs 保证每一项业绩正确 | 过度解读 verification | 提升信任与可比性 | 与 performance presentation 强关联 | 成本是流程和第三方验证费用 |

## 通用分析框架

### 框架1：Ethics 情境题判断树

1. 先抽事实：谁做了什么
2. 再找受影响方：client / employer / market / profession
3. 再问触发哪个 Standard
4. 最后问最佳做法是否比“最低合规”更严格

### 框架2：信息题判断树

1. 信息是否 nonpublic？
2. 是否 material？
3. 如果两者都满足：不能交易、不能建议、不能传播
4. 如果只是拼接公开信息：可能是 mosaic theory

### 框架3：冲突题判断树

1. 有无 personal benefit / compensation / relationship？
2. 是否需要 disclosure？
3. 披露后是否仍不足以消除不当影响？
4. 若仍不当，则不能仅靠 disclosure 解决

## 核心公式速查

| 指标 | 公式 | 考试说明 |
|------|------|----------|
| Ethics | 无核心数值公式 | 本科重在判断框架 |
| Priority Rule | `client > market integrity > employer/self convenience` | 先守客户与市场 |
| Stricter Standard Rule | `required conduct = max(applicable law, CFA Standards)` | law 与 Standards 冲突时常考 |
| MNPI Gate | `material AND nonpublic -> do not trade/recommend/disclose` | 信息题第一闸 |
| Suitability Gate | `client facts + portfolio context + risk/return fit` | 不是单产品热度判断 |
| Conflict Gate | `identify -> disclose -> avoid/mitigate if disclosure insufficient` | disclosure 不是橡皮擦 |
| GIPS Logic | `firm -> discretionary portfolios -> composites -> compliant presentation` | 结构化记忆链 |

## 高频考试陷阱速查

| 错误理解 | 正确理解 |
|----------|----------|
| 合法就一定合乎 Ethics | CFA 常要求高于法律底线 |
| 披露冲突后就什么都能做 | 有些冲突仅披露仍不充分 |
| mosaic theory 可以用内幕消息 | mosaic 不能包含 MNPI |
| fair dealing = 所有人必须完全同价同时成交 | 核心是合理、公平分配机会 |
| suitability = 推荐热门产品给所有客户 | 要匹配客户 objectives/constraints |
| confidentiality 永远不能破 | 法律要求、客户授权、违法调查时可例外 |
| employer 不允许跳槽前准备 | 可做有限准备，但不能挖客户/盗取资料 |
| referral fee 不用说，只要不影响建议 | 必须披露 |
| verification = GIPS 业绩一定没错 | verification 是 process-level assurance |
| 可以说自己“passed all CFA levels except charter pending”来营销 | 对 designation 引用要严格、不能夸大 |
| 用第三方研究就不用自己查合理依据 | 仍要评估研究质量与适用性 |
| 准备跳槽时先复制客户列表最有效率 | 准备可有限，盗资料和不当招揽不行 |
