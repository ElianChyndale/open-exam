# Ethical and Professional Standards MOC

> **一句话核心**：用 Code and Standards 判断专业行为、利益冲突、客户责任与合规边界。

## 1. Subject Brief 科目定位

- **Exam weight**: 15-20%
- **Official modules**: 5
- **Core question**: Does the conduct comply with the stricter of applicable law and CFA Standards, protect clients and market integrity, and withstand professional scrutiny?
- **Learning path**: M01 ethics foundation -> M02 Code/Standards map -> M03 Standards I-VII guidance -> M04 GIPS -> M05 comprehensive application.
- **Output standard**: `facts -> affected party -> Standard(s) -> violation test -> best action -> documentation`.

## 2. Formula & Framework Map 公式与框架地图

### A. Ethics Foundation / Code Map

| Framework | Structure | Exam use |
|---|---|---|
| Profession trust chain | specialized knowledge + service orientation + code/standards + discipline process -> public trust | 区分 profession 与 ordinary occupation；特别关注 client focus 和 code/enforcement。 |
| Ethics vs Legal | legal: minimum permissible; ethics: higher standard; conflict -> stricter rule | 合法不等于合道德，CFA Standards 可能高于法律底线。 |
| Ethical decision framework | identify facts/stakeholders/duties/conflicts -> consider alternatives -> act -> reflect | 案例题操作骨架不独立成题，但贯穿所有 Standards。 |
| Professional Conduct Program | CFA Institute investigates, disciplines, enforces Code/Standards for members/candidates | Code/Standards 有约束力，不是建议。 |
| Code of Ethics six components | integrity, competence, diligence/respect, client/employer duty, professionalism/market integrity, professional competence | 知道这是 broad principles，具体判断在 Standards I-VII。 |

### B. Standard I: Professionalism

| Gate | Decision rule | Exam use |
|---|---|---|
| I(A) Knowledge of the Law / Stricter Standard Rule | `required conduct = max(applicable law, regulation, CFA Standards)` | 法律与 Standards 冲突时选更严格；发现违法要 dissociate。 |
| I(B) Independence / Objectivity | benefit/pressure -> could impair objectivity? -> reject/disclose/seek consent | gifts, issuer-paid research, banking pressure, travel funding。 |
| I(C) Misrepresentation | no false claims about credentials, performance, services; cite third-party sources; correct errors | Plagiarism, Omissions, Social media, Performance reporting。 |
| I(D) Misconduct | dishonesty, fraud, deceit, or actions harming profession reputation | 不仅限工作场合，personal conduct 也可能触发。 |
| I(E) Competence | maintain and improve professional skills; only act within competence | New role, new product, continuing education。 |

### C. Standard II: Integrity of Capital Markets

| Gate | Decision rule | Exam use |
|---|---|---|
| II(A) MNPI Gate | `material AND nonpublic -> do not trade/recommend/disclose` | 信息题第一闸。Mosaic theory 不能包含 MNPI。 |
| II(B) Market Manipulation | no false/misleading price, volume, or information signals | Information-based 与 transaction-based manipulation。 |

### D. Standard III: Duties to Clients

| Gate | Decision rule | Exam use |
|---|---|---|
| III(A) Loyalty, Prudence, Care | client interest first; manage assets with reasonable care | Identity actual client (plan participants vs sponsor)。 |
| III(B) Fair Dealing | investment actions disseminated fairly; allocation by documented policy | Fair = documented allocation, not necessarily same price/time。 |
| III(C) Suitability | client facts + IPS/objectives/constraints + portfolio context + product risk/return | 在整个 portfolio context 判断，不是单产品。 |
| III(D) Performance Presentation | not misleading; include material facts; support claims | Link to GIPS for specific standards。 |
| III(E) Confidentiality | keep client info confidential unless exception applies | Exceptions: client authorization, legal requirement, illegal activity。 |

### E. Standard IV-V: Employers and Investment Process

| Gate | Decision rule | Exam use |
|---|---|---|
| IV(A) Employer Loyalty / Exit Gate | limited preparation OK; no client solicitation, records theft, or property misuse | 跳槽题高频。 |
| IV(B) Additional Compensation | outside compensation must be disclosed and consented in writing | Anything beyond regular employer compensation。 |
| IV(C) Responsibilities of Supervisors | establish and enforce reasonable compliance procedures | 不知道下属违规不代表免责。 |
| V(A) Diligence and Reasonable Basis | research/recommendations need sufficient due diligence and data support | Using third-party research, quantitative models, subadvisers。 |
| V(B) Communication | distinguish fact from opinion; disclose risks, limits, methodology changes | Cost disclosure, process changes, risk limitations。 |
| V(C) Record Retention | retain records supporting analysis, recommendations, actions | Records are firm property, not employee property。 |

### F. Standard VI-VII: Conflicts and CFA Responsibilities

| Gate | Decision rule | Exam use |
|---|---|---|
| VI(A) Disclosure of Conflicts | identify -> disclose prominently -> mitigate/avoid if insufficient | Disclosure is not an eraser。 |
| VI(B) Priority of Transactions | client trades before employer/personal trades | Personal trading restrictions。 |
| VI(C) Referral Fees | disclose all referral compensation to clients/prospective clients | Non-cash and soft-dollar also covered。 |
| VII(A) Conduct in CFA Program | no cheating, sharing exam content, or disrupting program integrity | Exam confidentiality。 |
| VII(B) CFA Designation | accurate, factual use only; no implication of superior performance | "Passed all levels" vs charterholder distinctions。 |

### G. GIPS Framework (M04)

| Gate | Decision rule | Exam use |
|---|---|---|
| Claim compliance | only firm can claim; must be firm-wide | Individual/composite cannot independently claim。 |
| Composite inclusion | all actual fee-paying discretionary portfolios meeting strategy definition | No cherry-picking。 |
| Fundamentals | input data quality, consistent calculation methodology, required disclosures | Fair representation + full disclosure。 |
| Verification | independent third-party review of firm-level processes | Process assurance, not return guarantee。 |

### H. Ethics Application Case Triage (M05)

| Step | Action |
|---|---|
| 1. Lock facts | Who did what, when, to whom, with what information? |
| 2. Identify affected parties | Client, employer, market, profession, CFA Program |
| 3. Map to Standard | I through VII, including subsection |
| 4. Violation test | Does conduct violate required conduct? |
| 5. Best action | Stop -> disclose/escalate -> dissociate if necessary -> document |

## 4. Curriculum Spine 教材主线

1. **Why ethics matters**: M01 建立 ethics/profession/trust 底座，回答为什么投资行业需要高于法律底线的行为标准。
2. **Code and Standards structure**: M02 给出 Code of Ethics 六项总纲和 Standards I-VII 分类索引。
3. **Standard-by-standard guidance**: M03 逐条展开 I-VII 的 required conduct, recommended procedures 和 application examples。
4. **Performance presentation standard**: M04 GIPS 把 III(D) 的具体化——firm/composite/verification。
5. **Comprehensive application**: M05 把所有 Standards 放在综合案例中，要求完整的事实->判断->行动链。

## 5. Exam Routes 做题路线

- **Violation route**: 识别行为 -> 定位 affected party -> 选择 Standard(s) subsection -> 判断是否违反 required conduct -> 确定 best action。
- **Stricter rule route**: 当地法律 vs CFA Standards -> 哪个更严格就选哪个 -> dissociate 条件。
- **MNPI route**: 信息 material? -> nonpublic? -> both -> no trade/recommend/share; mosaic allowed only without MNPI。
- **Conflict route**: 是否存在 personal benefit/compensation/relationship? -> 是否充分显著披露? -> 披露后是否仍不够?。
- **Employer exit route**: 离职准备边界? -> 有无挖客户/带走记录/利用公司财产?。
- **GIPS route**: firm 定义 -> discretionary portfolios -> composites -> compliant presentation -> verification。
- **Case triage route**: facts -> affected parties -> Standards -> violation test -> best action -> documentation。

## 6. Practice & Mock Evidence Map 题库证据地图

- **Subject practice page**: [[00-Ethics-Practice-Questions]]
- **Evidence rule**: Ethics 以案例判断为主，高频考点集中在 I(A) law/standards, I(B) independence, II(A) MNPI, III(C) suitability, IV(A) loyalty, VI(A) conflicts, VII(B) designation。
- **Mock review tag**: tag every miss as the relevant Standard and subsection for systematic repair。

## 7. Review Routes 复习路线

- **Fast route 30 min**: Stricter standard rule -> MNPI gate -> suitability gate -> conflict gate -> loyalty gate -> CFA designation。
- **Deep route half day**: M01 M02 foundation -> M03 Standard I-VII guidance -> M04 GIPS -> M05 application cases。
- **Error route**: if Standard misidentified, rebuild from affected party -> I-VII -> subsection. If best action wrong, check stop/disclose/escalate/dissociate order。
- **Pre-mock route**: rehearse each gate decision rule, especially I(A) dissociation, I(B) independence threats, II(A) MNPI/mosaic, III(C) suitability, IV(A) exit boundaries, VI(A) disclosure limits, VII(B) accurate designation use。
