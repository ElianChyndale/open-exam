# M05: 准则 III：对客户的义务 (Standard III: Duties to Clients)

## 1. 核心知识点 (Core Knowledge Points)

### III(A) 忠诚、审慎与谨慎 (Loyalty, Prudence, and Care)

**核心义务**：以客户利益为首要考虑，以受托人 (fiduciary) 身份行事。

**关键维度**：
- **客户利益 (client benefit)** — 所有行动应从客户最佳利益出发
- **受托人意识 (fiduciary mindset)** — 高于普通合同义务的法律标准
- **软美元 (soft dollars)** — 必须合理使用且使客户受益
- **代理投票 (proxy voting)** — 必须按照客户最佳利益行使投票权

### III(B) 公平交易 (Fair Dealing)

**核心义务**：在推荐传播和交易分配中公平对待所有客户。

**关键要点**：
- 不是要求完全同时同价成交，而是合理的、公平的分配机制
- 推荐必须公平地向所有客户传播，不能给特定客户提前通知
- 交易分配必须公平，特别是 IPO 和限量配售

**常见场景**：
- 限价单未全部成交 → 按比例分配
- 利好消息 → 所有客户同时知情，不能提前通知大客户

### III(C) 适当性 (Suitability)

**核心义务**：在了解客户的投资目标、约束和风险承受能力的基础上做出推荐。

**两个层次**：
1. **了解客户 (Know Your Client, KYC)** — 调查客户的 objectives 和 constraints
2. **投资组合背景 (portfolio context)** — 不能孤立看待单一产品，要在整体投资组合中评估适当性

**判断标准**：不是单一产品的热度或收益潜力，而是是否匹配客户的具体情况 (not a single-product popularity judgment)。

### III(D) 业绩陈述 (Performance Presentation)

**核心义务**：公平、准确、完整地沟通投资业绩信息。

**关键要求**：
- 不能选择性展示最佳业绩
- 必须披露计算方法和假设
- 不能做虚假或误导性的业绩陈述

### III(E) 保密义务 (Preservation of Confidentiality)

**核心义务**：保护客户信息机密性。

**例外情形 (exceptions)**：
1. **客户许可 (client permission)** — 客户授权披露
2. **法律要求 (law requirement)** — 法院传票或监管要求
3. **违法活动处理 (illegal activity handling)** — 涉及违法活动的防范和调查

**注意**：保密义务是持续的，即使客户关系终止后仍然存在。

## 2. 关键判断框架 (Key Frameworks)

### 客户义务优先序

```
客户利益 (client) > 市场诚信 (market integrity) > 雇主/个人利益 (employer/self)
```

### 适当性判断逻辑

```
了解客户 (objectives + constraints) → 评估投资组合背景 → 判断具体推荐是否适当
```

## 3. 常见考点与解题思路 (Exam Tips)

### 考点 1：公平交易的边界
- **典型场景**：机构客户和个人客户同时下单，机构客户获得更好的价格
- **解题思路**：需要有客观的分配政策并公平执行。如果按照预设的公平程序执行，不违反 fair dealing

### 考点 2：适当性的判断
- **典型场景**：向风险承受能力低的客户推荐高风险产品
- **解题思路**：违反 III(C)，因为 product 和 client 不匹配。关键在于是否做了充分的 KYC 和 suitability assessment

### 考点 3：保密的例外
- **典型场景**：监管机构要求提供客户交易记录
- **解题思路**：法律要求属于保密的例外，可以提供。但应当限于法律要求的范围，不额外披露

## 4. 易错点提醒 (Common Pitfalls)

| 错误理解 | 正确理解 |
|----------|----------|
| fair dealing = 所有人完全同价同时成交 | 核心是合理、公平分配机会 |
| suitability = 推荐热门产品给所有客户 | 要匹配客户 objectives/constraints |
| confidentiality 永远不能破 | 法律要求、客户授权、违法调查时可例外 |
| 客户关系结束保密义务也结束 | 保密义务在关系结束后仍然持续 |
| 业绩展示可以只选表现好的 | 必须公平、准确、完整 |
