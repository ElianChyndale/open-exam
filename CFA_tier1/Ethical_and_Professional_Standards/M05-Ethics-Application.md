### 🛠️ 常见考点与解题思路

**考点1：综合情境题 — 判断是否违反 CFA 标准**
- **典型问法**："下列哪项行为最可能违反 CFA 标准？"
- **解题思路**：逐一比对事实与各标准。注意题目可能涉及**多个标准**的交叉，需要选出最直接的违规项

**考点2：推荐最佳行动**
- **典型问法**："以下哪项是最适当的行动方案？"
- **解题思路**：优先选择最保守 (most conservative) 且符合 daylight test 的做法。通常：披露 → 回避冲突 → 保护客户利益

**考点3：多重违规识别**
- **典型问法**：一段描述中，分析师的行为违反了哪些标准？
- **解题思路**：不要只找一个违规点。列出所有可能的违规，再排除明显不成立的。特别注意：一个行为可能同时违反多个标准

**考点4：伦理决策框架的应用**
- **典型问法**："按照伦理决策框架，分析师下一步应做什么？"
- **解题思路**：依托 7 步框架判断当前所处阶段，选择对应的下一步行动

**考点5：法律 vs. CFA 标准**
- **典型问法**："某行为在 A 国合法，但违反 CFA 标准，应如何处理？"
- **解题思路**：遵循更严格者。CFA 标准可能要求高于当地法律，但不能要求违反法律

### 🚨 易错点与考试陷阱

| ❌ 错误理解 | ✅ 正确理解 |
|-----------|-----------|
| 只要未违法，就不会违规 CFA 标准 | 合法但可能违反 CFA 标准；需遵循更严格者 |
| 披露冲突后就可以做任何事 | 披露是最低要求，某些冲突即使披露也不可接受 |
| 使用第三方研究就不用自己查合理依据 | 仍需评估第三方研究的质量与适用性 (V(A)) |
| 情境题只要找到一条标准就够 | 需考虑是否同时触发多条标准，选最直接的违规 |
| MNPI 只有交易才违规 | 传播、推荐他人交易同样违规 |
| 客户第一意味着永远不拒绝客户要求 | 客户利益≠客户所有要求；需符合法律和标准 |
| 冲突只在有明显利益时才需披露 | 任何可能影响独立性的利益都需披露 |

### 📋 案例研究

**案例研究 1：分析师的双重身份冲突**

**场景**：
分析师张某在一家卖方研究机构工作，负责覆盖 T 公司的股票。张某私下持有 1,000 股 T 公司股票（占其个人投资组合的 15%）。张某发布了一份关于 T 公司的买入报告，报告中未提及个人持股。报告发布后 T 公司股价上涨 15%，张某的个人账户因此获利。

**问题**：
1. 张某的行为违反了哪些 CFA 标准？
2. 张某最适当的做法应该是什么？

**分析**：

| 评估维度 | 分析 |
|----------|------|
| 触发标准 | VI(A) Disclosure of Conflicts — 持有被推荐证券的实益所有权但未披露 |
| 触发标准 | I(B) Independence and Objectivity — 个人利益可能影响推荐客观性 |
| 触发标准 | III(A) Loyalty to Clients — 客户利益可能受到个人利益影响 |
| 受影响方 | 客户（报告使用者）、市场完整性 |
| 更严格做法 | 在发布报告前披露持股；或建立个人交易限制政策 |
| 最适当行动 | ① 披露实益所有权；② 避免在报告发布前后进行个人交易；③ 考虑将持仓放入盲信 (blind trust) |

**结论**：违反 VI(A) 和 I(B)。最适当做法是在推荐前完整披露利益冲突，并避免个人交易与推荐的时间重合。

---

**案例研究 2：客户信息与法律义务的冲突**

**场景**：
投资顾问李某的客户王某被发现使用其投资账户进行可疑交易，可能涉及洗钱。当地法律要求金融机构报告可疑交易活动，但王某强烈要求李某保密，并威胁如果报告将转走全部资产。

**问题**：
1. 李某面临哪些标准和法律义务的冲突？
2. 李某应如何平衡保密义务与法律要求？

**分析**：

| 评估维度 | 分析 |
|----------|------|
| 触发标准 | III(E) Preservation of Confidentiality — 客户要求保密 |
| 触发法律 | 反洗钱 (AML) 报告义务 |
| 保密例外 | III(E) 允许的例外：法律要求、客户授权、违法调查 |
| 受影响方 | 客户、社会公众、职业诚信 |
| 优先规则 | 法律要求优先（涉及非法活动时保密义务有例外） |
| 最适当行动 | ① 向客户解释保密的法定例外；② 按照法律要求提交可疑交易报告；③ 保留合规记录 |

**结论**：虽然 III(E) 要求保护客户保密性，但法律要求报告和非法活动是保密义务的正当例外。李某应依法报告，并向客户解释无法承诺保密的原因。

---

**案例研究 3：新客户推荐与适当性判断**

**场景**：
赵某是一名 CFA 持证人，新客户陈先生前来咨询投资建议。陈先生 65 岁，即将退休，投资目标是保本和稳定收益。赵某所在公司近期推出了一支高收益债券基金，佣金率高于其他产品。赵某向陈先生推荐了这支基金，理由是"高收益能跑赢通胀"。赵某未告知陈先生该基金的高佣金率，也未提供其他低风险选项。

**问题**：
1. 赵某的行为违反了哪些 CFA 标准？
2. 赵某应如何正确进行评估和推荐？

**分析**：

| 评估维度 | 分析 |
|----------|------|
| 触发标准 | III(C) Suitability — 高风险基金不匹配退休保本的保守目标 |
| 触发标准 | III(A) Loyalty, Prudence, and Care — 未将客户利益置于首位 |
| 触发标准 | VI(A) Disclosure of Conflicts — 未披露佣金利益冲突 |
| 触发标准 | I(C) Misrepresentation — "高收益能跑赢通胀"可能构成误导陈述 |
| 受影响方 | 客户（面临不适当风险）、职业诚信 |
| 最适当行动 | ① 全面调查客户的投资目标、风险承受能力和时间 horizon；② 推荐与客户情况匹配的产品；③ 披露所有费用和佣金；④ 提供多种选项供客户选择 |

**结论**：违反 III(C)、III(A)、VI(A)。赵某应当首先完成客户适当性评估 (suitability assessment)，在投资组合背景下进行推荐，并充分披露佣金结构。
