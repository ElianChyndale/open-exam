# M05: Ethics Application

## 0. Reading Contract 学习契约

- **Official scope**: evaluate practices, policies, and conduct relative to Code of Ethics and Standards I-VII; explain whether conduct violates Code and Standards.
- **C+ output**: 给定综合案例，能完成完整 case triage（facts -> affected parties -> Standards -> violation test -> best action）。
- **Evidence anchor**: V10 Module 5；注意该模块 practice/solutions 在 registry 中未单独列出，以教材内 end-of-reading questions 为准。

## 1. Module Brief 模块定位

M05 是 Ethics 的最终整合模块。M01 提供 ethics/profession/trust 底座，M02 提供 Standards 索引，M03 展开每条 guidance，M04 处理 GIPS 专项。M05 要求你把它们串成完整的事实->判断->行动链：给定一个真实案例场景（通常跨 Standards），识别事实 -> 定位 Standards -> 判断违规 -> 选择最佳行动。每个 case 都可能同时触发多个 Standards 的 subsection。

## 2. Curriculum Spine 教材正文主线

### 2. Professionalism Cases
- **Knowledge of the Law (I(A))**: Mandracken, Pellie, Mwangi cases — stricter standard rule, dissociating from violations, knowing participation。
- **Independence and Objectivity (I(B))**: Myers case — conflicts from banking relationships, issuer-paid research。
- **Misrepresentation (I(C))**: Lee, Andersen, Brodeur cases — plagiarism, model misrepresentation, performance claims。
- **Misconduct (I(D))**: Hanse, Mang cases — fraud, personal conduct harming profession。
- **Competence (I(E))**: Mahajan case — acting outside competence, need for continuing education。

### 3. Integrity of Capital Markets Cases
- **MNPI (II(A))**: Khatri, Kwame cases — materiality determination, mosaic theory limits, expert network use。
- **Market Manipulation (II(B))**: Abbha case — transaction-based manipulation, creating false volume。

### 4. Duties to Clients Cases
- **Loyalty/Prudence/Care (III(A))**: Maste, Gaini, Braung cases — best execution, directed brokerage, identifying actual client。
- **Fair Dealing (III(B))**: Scherzer case — selective disclosure, trade allocation fairness。
- **Suitability (III(C))**: Marte, Duri cases — IPS compliance, risk profile, portfolio context, unsolicited orders。
- **Performance Presentation (III(D))**: Jergenn case — performance calculation methodology, selective presentation。
- **Confidentiality (III(E))**: Giddings and Marsh case — disclosure exceptions, accidental disclosure。

### 5. Duties to Employers Cases
- **Loyalty (IV(A))**: Nickoli, Kuznetsov, Clemence cases — departing employees, client solicitation, independent practice。
- **Additional Compensation (IV(B))**: Estevez case — written consent for outside compensation。

### 6. Investment Analysis, Recommendations, Actions Cases
- **Reasonable Basis (V(A))**: due diligence, third-party research reliance, quantitative model validation。
- **Communication (V(B))**: costs disclosure, risk/limits communication, fact vs opinion。
- **Records (V(C))**: record retention obligations。

### 7. Conflicts of Interest Cases
- **Disclosure (VI(A))**: business relationships, stock ownership, compensation conflicts。
- **Priority (VI(B))**: personal trading, family accounts, blackout periods。
- **Referral Fees (VI(C))**: disclosure of referral arrangements, soft-dollar referrals。

### 8. Responsibilities as CFA Member/Candidate Cases
- **Program Conduct (VII(A))**: exam confidentiality, sharing exam content。
- **Designation (VII(B))**: accurate use of CFA designation, distinguishing charterholder from candidate。

## 3. Exam Translation 考试翻译

- `case triage` -> 每个综合案例的第一步：锁定 facts, actors, timeline, affected parties, disclosures, approvals。
- `violation test` -> 先问 "does this conduct violate required conduct under the relevant Standard?"
- `best action` -> stop -> disclose/escalate -> dissociate -> document; 选择最保守保护客户和市场的行动。
- `recommended procedure` -> 没有 violation 时仍可能改进；separate best practice from required conduct。
- `cross-Standard cases` -> 同一案例行为可能触发多个 Standard 的 subsection，必须分别判断。

## 4. Formula & Decision Bench 公式与决策台

| Step | Action | Output |
|---|---|---|
| 1. Lock facts | Who did what, when, to whom, with what information, with what disclosure/approvals? | Fact summary |
| 2. Identify affected parties | Client, employer, market, profession, CFA Institute | Party list |
| 3. Map to Standards | Match each conduct to Standard/subsection | Standard list |
| 4. Violation test | Does conduct violate required conduct? (yes/no per Standard) | Violation finding |
| 5. Best action | Stop/refuse -> disclose/recuse/restrict -> escalate -> dissociate -> document | Action plan |
| 6. Recommended procedure | Propose policy/procedure to prevent recurrence | Preventive measure |

**Key gate rules (same as M03)**:
- I(A) stricter standard: `required conduct = max(law, regulation, Standards)`
- I(B) independence: benefit/pressure impairs objectivity -> reject/disclose/manage
- II(A) MNPI: material AND nonpublic -> no trade/recommend/share
- III(C) suitability: client facts + IPS + portfolio context + risk/return fit
- IV(A) loyalty: limited prep OK; client solicitation/theft/records not OK
- VI(A) conflicts: identify -> disclose -> mitigate if insufficient
- VII(B) designation: accurate factual use; no performance implication

## 5. Practice & Mock Evidence 题库证据

- Expected item types: full case analysis evaluating practices and policies against Code and Standards, identifying violations, recommending best actions.
- Review tag: `Ethics-M05-application`.
- High-frequency trigger: employer exit cases often combine IV(A) + VI(A); research cases combine V(A) + V(B) + VI(A); performance cases combine III(D) + I(C) + GIPS。

## 6. Trap Ledger 陷阱账本

| Trap | Fix |
|---|---|
| 只定位到一个 Standard | Cross-Standard 案例需要分别检视每个行为触发哪个 subsection。 |
| 跳过 violation test 直接说 best practice | 先判断是否违反 required conduct，再问 recommended procedure。 |
| Disclosure = everything fixed | VI(A) 有些冲突仅 disclosure 不够，仍需 mitigate/avoid。 |
| 跳槽 case 只看到 IV(A) | 检查是否同时涉及 VI(A) conflicts 和 V(C) records。 |
| Performance case 只看 III(D) | 也可能涉及 I(C) misrepresentation 和 GIPS violations。 |
| 只找 case "主角"的违规 | 监督者（IV(C)）和批准者（I(A) knowing participation）也可能违规。 |

## 7. Final Recall Sheet 最后回忆页

- **Case triage sequence**: facts -> affected parties -> Standards -> violation test -> best action -> documentation。
- **Every case starts with**: Who is affected? Client, employer, market, or CFA Program?
- **Cross-Standard check**: one behavior can trigger multiple subsections。
- **Best action priority**: stop/refuse -> disclose/recuse -> escalate -> dissociate -> document。
- **Most conservative answer**: the one that protects client and market integrity, withstands public scrutiny, and is documented。
