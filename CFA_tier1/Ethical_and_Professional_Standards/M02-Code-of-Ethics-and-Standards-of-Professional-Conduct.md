# M02: Code of Ethics and Standards of Professional Conduct

## 0. Reading Contract 学习契约

- **Official scope**: Professional Conduct Program structure and enforcement, Code of Ethics six components, seven Standards of Professional Conduct map.
- **C+ output**: 能说出 Code of Ethics 的 broad principles，能用 Standards I-VII 分类索引对案例行为做初步定位。
- **Evidence anchor**: V10 Module 2, practice and solutions available in the 2026 ePub index.

## 1. Module Brief 模块定位

M02 是 Standards 的目录和索引层。Code of Ethics 给出 broad principles，Standards I-VII 给出行为分类地图。本模块不展开每条 Standard 的具体 guidance（M03 负责），但要求你见过 Standards 名称和覆盖范围，知道从 affected party 和 conduct type 能定位到 I-VII 中的类别。M03/M05 在此基础做精细判断。

## 2. Curriculum Spine 教材正文主线

1. **Professional Conduct Program**: 调查、纪律、enforcement 机制；Code/Standards 对 members 和 candidates 有约束力。
2. **Evolution of the Code and Standards**: 2023 年修订——新增 Competence Standard、服务的性质和成本披露、conflicts 修订。
3. **Ethics and the Investment Industry**: ethics 为何重要、ethics vs regulation、firm-level commitment。
4. **Code of Ethics six components**: integrity/competence/diligence/respect；client/employer duty；professionalism/market integrity；professional competence。
5. **Standards of Professional Conduct I-VII 索引**:
   - I Professionalism (law, independence, misrepresentation, misconduct, competence)
   - II Integrity of Capital Markets (MNPI, manipulation)
   - III Duties to Clients (loyalty, fair dealing, suitability, performance, confidentiality)
   - IV Duties to Employers (loyalty, additional compensation, supervision)
   - V Investment Analysis, Recommendations, Actions (diligence, communication, records)
   - VI Conflicts of Interest (disclosure, priority, referral fees)
   - VII Responsibilities as CFA Member/Candidate (program conduct, designation)

## 3. Exam Translation 考试翻译

- `Professional Conduct Program` -> CFA Institute 调查和执行 Code/Standards，对 members/candidates 有约束力。
- `Code of Ethics` -> six broad principles，不直接给出具体违规判断。
- `Standards I-VII` -> 行为分类地图，每个 Standard 下有 subsections。
- `Competence Standard` -> 2023 新增，I(E)，要求只在能力范围内服务。
- `LOS identify` -> 考试要求能识别六项 Code 和七条 Standards 的名称和覆盖范围。

## 6. Trap Ledger 陷阱账本

- Code of Ethics 是 broad principles，不是具体违规判断工具——具体判断在 Standards I-VII 的 subsections。
- Standards locator 只是第一步定位，M03 才展开每条 guidance。
- 2023 修订的 Competence Standard 是 I(E)，不要混淆为 VII 的内容。
- Professional Conduct Program 对 members 和 candidates 都有约束力，不只是 charterholders。

## 7. Final Recall Sheet 最后回忆页

- Code of Ethics: 6 components (integrity, competence, diligence/respect, client/employer duty, professionalism/market integrity, professional competence).
- Standards I-VII: Professionalism, Market Integrity, Clients, Employers, Analysis, Conflicts, CFA Responsibilities.
- Affected party mapping: law/objectivity -> I, market -> II, client -> III, employer -> IV, research -> V, conflict -> VI, CFA -> VII.
- M02 = index/classification; M03 = detailed guidance; M05 = full application.
