# M04: Introduction to the Global Investment Performance Standards (GIPS)

## 0. Reading Contract 学习契约

- **Official scope**: why GIPS created, who can claim compliance, composites, fundamentals of compliance, verification.
- **C+ output**: 能解释 GIPS 是自愿但全面的业绩展示标准，能正确应用 firm/composite/verification 判断链。
- **Evidence anchor**: V10 Module 4, practice and solutions available in the 2026 ePub index.

## 1. Module Brief 模块定位

GIPS 是 III(D) Performance Presentation 的具体化全球标准。它要求自愿宣称合规的 firm 全面遵守公平展示和充分披露原则。考试重点不在深层审计技术，而在 firm/composite/verification 三个核心概念及常见的误解陷阱。

## 2. Curriculum Spine 教材正文主线

1. **Why GIPS was created**: 解决业绩展示中的 cherry-picking 和不一致问题，提高全球可比性和可信度。
2. **Who can claim compliance**: 只有 firm（不是个人、composite、账户或部门）可以 claim；必须 firm-wide，不能选择性合规。
3. **Who benefits from compliance**: 投资管理 firm（获取/留住客户）、投资者（可比信息）、整体行业（可信度）。
4. **Composites**: 按相似策略/目标/限制的 portfolios 集合，必须包含所有符合条件的 discretionary portfolios。
5. **Fundamentals of Compliance**: firm definition、input data quality、calculation methodology、disclosures、presentation/reporting。
6. **Verification**: 独立第三方检查 firm-level 合规流程，不保证单个 composite 或 return number 正确。

## 3. Exam Translation 考试翻译

- `GIPS` -> 自愿标准；claim compliance 后必须全面遵守。
- `firm` -> 明确的投资管理业务单元；不能随意改变定义选业绩。
- `composite` -> 包含所有 discretionary portfolios matching strategy；不能 cherry-pick。
- `discretion` -> 必须明确区分 discretionary vs non-discretionary。
- `verification` -> 评估 firm-level compliance process，不是 return guarantee。
- `III(D) link` -> GIPS 是关于业绩展示的更高标准；III(D) 是基本原则。

## 4. Formula & Decision Bench 公式与决策台

| Trigger | Decision rule | Check |
|---|---|---|
| Claim compliance | claimant must be firm -> firm-wide -> all requirements met | 个人、账户、composite 不能单独 claim。 |
| Composite inclusion | discretionary + meets strategy definition -> must include | 不能选择性包含/排除。 |
| Fair representation | complete data + consistent method + required disclosures + no misleading selection | 与 III(D) 连接。 |
| Verification | independent review of firm policies/processes | 不是 return guarantee。 |
| Key sections sequence | fundamentals -> input data -> calculation -> composite construction -> disclosures -> presentation -> real estate/PE -> verification | 识别为主，无需深层技术。 |

## 6. Trap Ledger 陷阱账本

- GIPS 是自愿的，但它有约束力——一旦 claim 必须全面遵守。
- 只有 firm 能 claim；person、portfolio、composite 不能独立 claim。
- Firm 定义不能随意改变；不能只包括业绩好的账户或策略。
- Verification 是 process-level assurance，不是每个收益率数字的保证。
- Non-discretionary 账户不能进入 GIPS composites。

## 7. Final Recall Sheet 最后回忆页

- GIPS: fair representation + full disclosure + global comparability.
- Claim by firm only; must be firm-wide.
- Composite: all discretionary portfolios matching strategy.
- Verification: independent + firm-level process + not return guarantee.
- Standard III(D) link: GIPS is the specific standard for performance presentation.
