# M03: Guidance for Standards I-VII

## 0. Reading Contract 学习契约

- **Official scope**: Standards I-VII required conduct, recommended procedures, and application examples for every subsection.
- **C+ output**: 给定案例行为，能定位到具体 Standard/subsection，判断是否违反 required conduct，并给出 recommended procedure 或 best action。
- **Evidence anchor**: V10 Module 3, practice and solutions available in the 2026 ePub index.

## 1. Module Brief 模块定位

M03 是 Ethics 的核心判断模块。M02 给出 Standards I-VII 的索引，本模块逐条展开 required conduct、recommended procedures 和 application examples。每条 Standard 的核心是：什么行为违规、什么程序可以防止违规、披露是否足够、最佳行动是什么。M05 在此基础上做跨 Standards 综合案例判断。

## 2. Curriculum Spine 教材正文主线

### Standard I: Professionalism
- **I(A) Knowledge of the Law**: 遵守更严格的法律/法规/Standards；发现违法要 dissociate；不能 knowingly participate or associate with violations。
- **I(B) Independence and Objectivity**: 礼物、压力、issuer-paid research、banking relationship、travel funding 不能损害独立判断。
- **I(C) Misrepresentation**: 不得误导学历、业绩、模型、服务、第三方资料；引用外部材料要注明来源；Omissions 和 plagiarism 也属于 I(C)。
- **I(D) Misconduct**: 涉及 dishonesty、fraud、deceit 或影响职业声誉的行为违规——不仅限工作场合。
- **I(E) Competence**: 只在能力范围内服务，保持并提升专业能力。

### Standard II: Integrity of Capital Markets
- **II(A) Material Nonpublic Information**: material AND nonpublic -> 不交易、不推荐、不传播。Mosaic theory 不能包含 MNPI。
- **II(B) Market Manipulation**: 禁止制造虚假价格/成交量（transaction-based）或传播误导信息（information-based）。

### Standard III: Duties to Clients
- **III(A) Loyalty, Prudence, Care**: 客户利益优先，管理客户资产要审慎。Actual client 可能是 plan participants 而非 sponsor。
- **III(B) Fair Dealing**: 机会和推荐要公平传播，分配按既定政策。公平不等于所有客户同价同秒。
- **III(C) Suitability**: 了解客户 objectives/constraints/risk profile，在整个 portfolio context 判断。Unsolicited orders 要告知风险。
- **III(D) Performance Presentation**: 业绩陈述不得误导、要有合理依据和充分披露。Link to GIPS。
- **III(E) Confidentiality**: 保密，除非 client authorization / legal requirement / illegal activity inquiry。

### Standard IV: Duties to Employers
- **IV(A) Loyalty**: 可为离职做有限准备，但不能挖客户、带走资料或使用公司财产损害雇主利益。Whistleblowing 不属于 disloyalty。
- **IV(B) Additional Compensation**: 任何超出常规雇主报酬的 compensation（包括 client bonus）需书面同意。
- **IV(C) Responsibilities of Supervisors**: 主管要建立并执行合理合规程序；不知道下属违规不必然免责。

### Standard V: Investment Analysis, Recommendations, and Actions
- **V(A) Diligence and Reasonable Basis**: 研究和推荐必须有合理充分依据；使用第三方研究、量化模型、subadvisers 仍需 diligence。
- **V(B) Communication with Clients**: 区分事实和观点，披露假设、风险、限制、方法变化和服务成本。
- **V(C) Record Retention**: 保留支持研究、推荐和行动的记录。Records 是 firm property，离职不能带走。

### Standard VI: Conflicts of Interest
- **VI(A) Disclosure of Conflicts**: 充分、公平、显著披露可能影响独立性的冲突。Disclosure is not an eraser——披露后仍不充分时应回避。
- **VI(B) Priority of Transactions**: 客户交易优先于雇主和个人交易。Personal trading 要受限制。
- **VI(C) Referral Fees**: 向客户/潜在客户披露 referral compensation（包括 non-cash）。

### Standard VII: Responsibilities as a CFA Institute Member or CFA Candidate
- **VII(A) Conduct in CFA Programs**: 不得作弊、泄题、扰乱考试或损害 program integrity。
- **VII(B) Reference to CFA Institute, CFA Designation, and CFA Program**: 不能夸大 CFA 称号、候选人身份或考试成绩含义。

## 3. Exam Translation 考试翻译

- `I(A) stricter standard` -> 法律与 Standards 冲突时选更严格；dissociate 不等于辞职（可以内部反对/隔离）。
- `I(B) independence threats` -> gifts, travel, issuer-paid, banking pressure, manager selection influence。
- `I(C) misrepresentation` -> 不只是故意说谎，omissions 和 plagiarism 也是。
- `I(D) misconduct` -> personal conduct（如涉及欺诈的私人行为）也可能违规。
- `II(A) MNPI` -> material AND nonpublic 两个条件缺一不可。
- `II(B) manipulation` -> information-based 和 transaction-based，不限于 price manipulation。
- `III(A) loyalty` -> soft dollars、proxy voting、directed brokerage 都看是否 best interest of client。
- `III(C) suitability` -> 需要在 whole portfolio context 判断，不是 single product。
- `III(E) confidentiality` -> 三个例外：client permission, legal requirement, illegal activity investigation。
- `IV(A) loyalty` -> 离职前准备可接受，但挖客户/带走记录不可以。
- `IV(C) supervision` -> 合理合规程序是前提；知道或理应知道下属违规时必须行动。
- `V(A) reasonable basis` -> group research 可以 disagree 但记录 minority opinion。
- `V(B) communication` -> 新修重点：要求 disclose nature of services and costs to clients。
- `VI(A) conflicts` -> disclosure 要充分、显著、公平；有些冲突仅 disclosure 不够。
- `VII(B) designation` -> "passed all three levels" vs "charterholder" 区别重要。

## 4. Formula & Decision Bench 公式与决策台

| Standard | Core rule | Key examples / traps |
|---|---|---|
| I(A) Knowledge of Law | `required conduct = max(law, regulation, Standards)` | dissociate when knows violations; cannot knowingly participate。 |
| I(B) Independence | benefit/pressure impairs objectivity -> reject/disclose/manage | gifts from clients may be OK; gifts from issuers normally not。 |
| I(C) Misrepresentation | no false/misleading claims; cite sources; correct errors | plagiarism even of public sources。 |
| I(D) Misconduct | no dishonesty, fraud, deceit harming profession reputation | 个人 fraud 行为也可能触发。 |
| I(E) Competence | within competence; maintain/improve skills | new products/roles need education。 |
| II(A) MNPI | material AND nonpublic -> no trade/recommend/share | mosaic allowed without MNPI。 |
| II(B) Manipulation | no false price/volume/information signals | pump-and-dump, spreading false rumors。 |
| III(A) Loyalty | client interest first; best execution; vote proxies | soft dollars must benefit client。 |
| III(B) Fair Dealing | disseminate fairly; allocate by documented policy | not same price, not same time. |
| III(C) Suitability | client objectives + constraints + portfolio context | IPS needed; update periodically。 |
| III(D) Performance | not misleading; include material facts | link to GIPS。 |
| III(E) Confidentiality | keep confidential; three exceptions | 不能为方便披露。 |
| IV(A) Loyalty | limited prep OK; no solicitation/theft/misuse | independent practice may need consent。 |
| IV(B) Additional Comp | written consent from employer required | any outside comp。 |
| IV(C) Supervision | reasonable procedures; detect/prevent violations | cannot delegate away responsibility。 |
| V(A) Reasonable Basis | sufficient research and data | secondary research still needs validation。 |
| V(B) Communication | fact vs opinion; disclose risks/costs/limits | new: service and cost disclosure。 |
| V(C) Records | retain supporting records; firm property | retention period varies。 |
| VI(A) Conflicts | identify -> disclose -> mitigate if insufficient | disclosure is not an eraser。 |
| VI(B) Priority | client > employer > personal | no front-running。 |
| VI(C) Referral Fees | disclose to clients/prospective clients | non-cash referral also covered。 |
| VII(A) CFA Conduct | no cheating, no sharing exam content, no disrupting program | 考试保密严格。 |
| VII(B) CFA Designation | accurate factual use; no performance claim | "passed all levels" vs charterholder。 |

## 6. Trap Ledger 陷阱账本

| Trap | Fix |
|---|---|
| 合法行为=合 Standards | I(A) 要求 stricter standard，合法但违反比法律更严的 Standards 也违规。 |
| Disclosure fixes everything | VI(A) 披露后若 conflict 仍严重，需要 mitigate/avoid。 |
| Mosaic theory = use MNPI carefully | II(A) mosaic 不能包含 MNPI，material nonpublic 仍不能放入。 |
| Fair dealing = same price same time | III(B) 核心是 documented allocation，不是同价同秒。 |
| Suitability = single product check | III(C) 需要在 whole portfolio context 判断。 |
| Confidentiality 永远不能破 | III(E) 三个例外：authorization, law, illegal activity。 |
| 跳槽前不能做任何准备 | IV(A) limited preparation OK; 挖客户/记录/财产不可。 |
| 主管不知道=免责 | IV(C) 知道或理应知道都要行动，合理合规程序是前提。 |
| Group research = 必须一致同意 | V(A) 可以 disagree，记录 minority opinion 即可。 |
| "I passed all three levels" = charterholder | VII(B) 严格区分 member/candidate/charterholder。 |
