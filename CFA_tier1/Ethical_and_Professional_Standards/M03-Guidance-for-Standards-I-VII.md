## Learning Outcome Statements

The candidate should be able to:

- demonstrate the application of the Code of Ethics and Standards of Professional Conduct to situations involving issues of professional integrity
- recommend practices and procedures designed to prevent violations of the Code of Ethics and Standards of Professional Conduct
- identify conduct that conforms to the Code and Standards and conduct that violates the Code and Standards

## 核心知识树

本模块涵盖 Standards I-VII 共 24 条子标准的判例应用。

```text
Standard I: Professionalism
├── I(A) Knowledge of the Law — 了解法律，遵循更严格规则，远离违规
├── I(B) Independence and Objectivity — 保持独立判断，不受外部干预
├── I(C) Misrepresentation — 不作虚假/误导陈述，注明来源
├── I(D) Misconduct — 不从事损害职业声誉的行为
└── I(E) Competence — 维持专业能力水平

Standard II: Integrity of Capital Markets
├── II(A) Material Nonpublic Information — 禁止交易/推荐/传播 MNPI
└── II(B) Market Manipulation — 禁止信息扭曲和交易型操纵

Standard III: Duties to Clients
├── III(A) Loyalty, Prudence, and Care — 受托人义务，客户利益优先
├── III(B) Fair Dealing — 公平传播推荐，公平分配交易
├── III(C) Suitability — KYC + 组合背景，匹配客户情况
├── III(D) Performance Presentation — 公平准确完整沟通业绩
└── III(E) Preservation of Confidentiality — 保密义务（法定的例外）

Standard IV: Duties to Employers
├── IV(A) Loyalty — 在职忠诚 vs 有限离职准备
├── IV(B) Additional Compensation — 额外报酬需各方书面同意
└── IV(C) Responsibilities of Supervisors — 建立/监督合规程序

Standard V: Investment Analysis, Recommendations, and Actions
├── V(A) Diligence and Reasonable Basis — 独立评估研究质量
├── V(B) Communication — 区分事实/观点，披露风险
└── V(C) Records Retention — 记录保存（通常 5-7 年）

Standard VI: Conflicts of Interest
├── VI(A) Disclosure of Conflicts — 事前完整披露利益冲突
├── VI(B) Priority of Transactions — 客户 > 雇主 > 个人
└── VI(C) Referral Fees — 披露介绍费及相关安排

Standard VII: Responsibilities as CFA Institute Members or Candidates
├── VII(A) Conduct as Participants — 不泄露考试内容/材料
└── VII(B) Reference to CFA — 准确引用称号，不夸大
```

## 核心概念与判断规则

### 整体伦理决策框架

遇到伦理场景题时按以下顺序判断：

1. **哪个标准？** — 识别场景触及哪个 Standard（客户义务？雇主义务？市场诚信？）
2. **具体哪条子标准？** — 例如涉及信息不对称 → II(A) MNPI；客户推荐 → III(C) Suitability
3. **是否违规？** — 行为的本质（intent）和影响（effect）比形式更重要
4. **应该怎么做？** — 正确的补救/防范措施（报告、披露、远离等）

### Standard I — Professionalism

**I(A) 了解法律**
- **判断规则**：法律 vs CFA 标准冲突时，遵守更严格者
- **看到"不同国家法律差异"** → 逐条比较，取更严格标准
- **看到"同事违规"** → 先报告 supervisor/compliance → 未改善则记录 → 严重时离职
- **陷阱**：不知道法律 ≠ 免责。从业者有义务主动了解适用法律

**I(B) 独立性与客观性**
- **判断规则**：在影响发生之前保护判断（protect judgment before conflict）
- **看到"发行人付费旅行""贵重礼品"** → 可能影响独立性
- **看到"投行部施压分析师改评级"** → 明确违反 I(B)
- **看到"小额礼节性礼品"** → 通常可接受（reasonable and customary）

**I(C) 虚假陈述**
- **判断规则**：陈述必须真实、可验证、注明来源
- **看到"使用他人研报未注明"** → 剽窃，违反 I(C)
- **看到"承诺收益""保证不亏"** → 明确违规
- **看到"夸大资质或经验"** → 违反 I(C)

**I(D) 不当行为**
- **判断规则**：行为是否对职业诚信产生负面影响（不限于工作时间）
- **看到"个人生活中的诈骗/盗窃"** → 仍可能违反 I(D)

### Standard II — Integrity of Capital Markets

**II(A) MNPI 判断流程**：
```
信息是否非公开？→ No → 可使用
             → Yes → 是否重大？
                      → No → 可使用（属于马赛克素材）
                      → Yes → MNPI，禁止交易/推荐/传播
```

- **看到"高管透露未公开数据"** → 先判断是否重大+非公开
- **看到"从公开渠道拼凑信息"** → 马赛克理论，合法
- **看到"在各微信群讨论上市前信息"** → 传播 MNPI，违反 II(A)
- **关键区分**：马赛克 = 公开+非重大非公开信息的拼接；不等于可以使用 MNPI

**II(B) 市场操纵**
- 两种形式：基于信息的扭曲（散布谣言）和基于交易的虚假价格信号（洗售、对倒）
- **看到"通过一连串交易制造活跃假象"** → 交易型操纵，违反 II(B)

### Standard III — Duties to Clients

**III(A) 忠诚、审慎与谨慎**
- **判断规则**：客户利益 > 雇主/个人利益
- **看到"软美元""代理投票"** → 必须以客户最佳利益行事
- **看到"交易分配偏向特定客户"** → 需要公平的政策

**III(B) 公平交易**
- **判断规则**：不是同时同价，而是合理公平的分配机制
- **看到"提前通知大客户好消息"** → 违反 III(B)
- **看到"IPO 分配偏向高净值"** → 违反 III(B)，除非有预先确定的公平政策

**III(C) 适当性**
- **判断规则**：产品必须匹配客户的 objectives + constraints
- **看到"给保守客户推荐高风险产品"** → 违反 III(C)
- **看到"不了解客户就推荐"** → 先做 KYC，再判断适当性
- **注意**：适当性要考虑整体投资组合，不能孤立看单一产品

**III(D) 业绩陈述**
- **判断规则**：公平、准确、完整展示业绩
- **看到"只展示最佳业绩年份"** → 选择性展示，违反 III(D)

**III(E) 保密义务**
- **判断规则**：保护客户信息机密性
- **例外**：客户许可 | 法律要求 | 违法活动处理
- **陷阱**：关系结束后保密义务仍然存在

### Standard IV — Duties to Employers

**IV(A) 在职忠诚**
- **判断规则**：有限离职准备（简历、面试）OK；挖客户/盗资料 NOT OK
- **看到"跳槽前复制客户名单到个人设备"** → 违反 IV(A)

**IV(B) 额外报酬**
- **判断规则**：任何来自非雇主渠道的报酬需各方书面同意
- **看到"兼任外部董事获取报酬未告知雇主"** → 违反 IV(B)

**IV(C) 监督责任**
- **判断规则**：监督者有责任建立和执行合规程序
- **看到"下属违规，上级不知情"** → 不知情 ≠ 免责
- **看到"公司没有合规程序"** → 应推动建立，不作为也违规

### Standard V — Investment Analysis, Recommendations, and Actions

**V(A) 勤勉与合理依据**
- **判断规则**：独立评估研究质量，即使是第三方研究
- **看到"直接引用卖方研报不加评估"** → 违反 V(A)

**V(B) 沟通**
- **判断规则**：区分事实/观点，披露风险/局限性
- **看到"只讲收益预期不提示风险"** → 违反 V(B)

**V(C) 记录保留**
- **判断规则**：保留所有支持分析和建议的记录
- **通常要求**：5-7 年（按当地法律）

### Standard VI — Conflicts of Interest

**VI(A) 冲突披露**
- **判断规则**：事前完整披露可能影响独立性的利益关系
- **看到"推荐有持股的公司未披露"** → 违反 VI(A)
- **注意**：披露不是橡皮擦（disclosure is not an eraser）

**VI(B) 交易优先顺序**
- **优先级**：客户 > 雇主 > 个人
- **看到"个人先交易再执行客户单"** → 违反 VI(B)

**VI(C) 介绍费**
- **判断规则**：任何推荐客户所得报酬需事先披露
- **不限于现金**：非现金利益也需要披露

### Standard VII — Responsibilities as CFA Members/Candidates

**VII(A) CFA 项目参与者行为**
- **禁止**：泄露考试内容、讨论考试体验、分享材料
- **看到"考后讨论考题内容"** → 违反 VII(A)

**VII(B) 引用 CFA 称号**
- **允许**："I passed Level I"（如属实）；"I am a CFA charterholder"（仅 charterholder）
- **禁止**："CFA (passed Level II)"；"I am a CFA"；暗示 CFA 能保证投资表现

## 易错点与考试陷阱

| 错误理解 | 正确理解 |
|----------|----------|
| 不知道法律就可以免责 | 从业者有义务了解适用法律，ignorance ≠ defense |
| 披露了礼物/冲突就什么都能做 | 某些冲突仅披露仍不充分（disclosure is not an eraser） |
| 马赛克理论可以用非公开信息 | 马赛克只能使用公开和非重大非公开信息，不能含 MNPI |
| 改写他人内容不注明不算剽窃 | 改写未注明来源仍构成剽窃 |
| fair dealing = 所有人同价同时成交 | 核心是合理、公平的分配机制 |
| 推荐热门产品给所有客户 = 适当性 | 必须匹配客户 objectives/constraints，不能一刀切 |
| 保密义务在客户关系结束后终止 | 保密义务持续存在 |
| 跳槽前准备可以做任何事 | 可有限准备，但不能挖客户/盗取专有资料 |
| 用第三方研报就不用自己查依据 | 仍需独立评估研究质量与适用性 |
| 个人行为与职业无关 | 严重损害职业声誉的个人行为也违反 I(D) |
| 可以说自己是 CFA 即使还没拿到 charter | 只有 active charterholder 才能使用 CFA 称号 |
